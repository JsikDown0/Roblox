### 2-1. BISON 탱커형 — 답 받음(결정기록 8-4): 컨셉 아트 새로 · 방패 대신 몸 덧장갑. 프롬프트 보냄 → 컨셉 받으면 윤곽 읽기부터
조건(결정기록 8-3): 거점에서 몸으로 버티는 수비형 · 본인 방패·장갑(공병형 설치 방벽과 구분) · CETUS(끌어내는 통제형)와 구분 · 느린 근거리형 함정 → 짧은 방패 돌진 · 샷건 · 실루엣 2곳 이상.
유저에게 낸 질문(답부터 받을 것):
1. 방패: a 탑 방패(기본형 소형 방패 세로 1.5배, 아래 쐐기) / b 두 장 방패(버티기 때 아래 장이 내려옴)
2. 머리 이마 차양(지휘관 = 안테나, 탱커 = 차양) 넣을지
3. 빔사벨 뺄지(근접 = 방패 치기 돌진) `[제안: 뺌]`
4. 진행 방식: 컨셉 아트 새로(지휘관형처럼 — 프롬프트 드림) / 파츠만 추가(공병형처럼)

## 4. 유저 작업 선호 (이번 세션에서 확인)
- **보내기 전에 보이는 문제는 먼저 고친다**("아쉬운 점을 나한테 말하기 전에 수정해주면 안 되는 거야?"). 답에는 "보내기 전에 고친 것"으로 적는다.
- 2~3안을 원본 아트·지금 판과 나란히. 고르는 건 유저. 버린 안도 남긴다.
- 정수 기울기(45° · 1:2)만 — 애매한 기울기는 "삼각김밥"·계단 줄무늬.
- 뜻 없는 가로줄·홈은 싫어함(팔 가로줄 전부 뺌). 관절은 원형 + 직사각 블록(BISON f 경첩) 문법.
- 빈틈(배경이 비치는 틈)·붕 뜬 느낌 싫어함 → 관절 모양을 바꿔서라도 채움(고관절 하우징).
- 데칼(붉은 줄)은 모델 밖, 시트에선 미리보기 칠만.
- 발광 원 두 개 나란히 = 얼굴 함정 → 평소 검정.
- 답은 한국어, 짧고 정확하게. 설계 결정 전에 구성부터 묻는 흐름(지휘관·공병형 때와 같음).

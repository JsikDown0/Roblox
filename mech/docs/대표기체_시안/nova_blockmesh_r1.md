# NOVA 블록메시 r1 (2026-10-25)

GPT 컨셉 "PROJECT : NOVA" 를 최대한 원본에 가깝게 재현한 결과. 다른 방의 복셀판(nova_2033)을 다듬는 대신 방식을 바꿨다.

## 방식 — 복셀 → 블록메시
- 셀 격자 대신 **모서리 깎인 볼록 블록**(scipy ConvexHull)을 메시로 쌓는다. 블록마다 자유 회전 가능.
- `chunk()`: 큰 판을 n×n 조각으로 쪼개고 틈·높이 편차·기울기·노치·계단을 넣는다 → 컨셉의 "잘게 쪼개진 장갑판" 질감.
- 파츠 = pivot/parent/rot/pose + 좌우 미러. 332 블록 / 14,496 삼각형(로블록스 메시 한도 안).
- 렌더러 `mesh_render.py`: numpy z-buffer, 원근 카메라(fov), 그림자맵, SSAO, 스페큘러, 림라이트, 블록 이음선, 블룸.

## 파일 (project docs)
- `flagship_tools/blockmesh.py` — 블록 모델러
- `flagship_tools/mesh_render.py` — 렌더러
- `flagship_tools/compare_nova.py` — 컨셉과 나란히 비교 (hero / trio / ortho / views / upper)
- `대표기체_시안/nova_blockmesh_r1.py` — 기체 정의. **실행 시 `nova_mesh.py` 로 이름 바꿀 것**(compare가 그 이름으로 import)
- 비교용 이미지 `nova_ref.png`(컨셉), `other_room.png`(다른 방 시트)는 같은 폴더에 직접 두어야 함

실행: `python3 compare_nova.py trio out.png` (약 10초)

## 맞춘 것 (측정 기반)
- 카메라: 컨셉 큰 그림은 기체 **왼쪽 앞(yaw +38), 낮은 각도(pitch −10), fov 40**. 정면이 아니다.
- 비율: 컨셉 3면도 실루엣을 픽셀로 재서(1.545 셀/px) 어깨폭·다리 길이·머리 크기를 맞춤.
- 머리 1.55배 확대·전진(처음엔 어깨에 묻혔음). 어깨는 높고 좁은 세로 판으로 가슴과 분리.
- 구성: 왼손 아래 라이플(긴 개머리판), 오른쪽 바인더 + 오렌지 에너지 블레이드, 등 뒤 높은 마스트, 무릎·코어·어깨 오렌지 발광.

## 남은 차이 (정직하게)
- 디테일 밀도·불규칙성이 컨셉보다 낮다.
- 장갑판 사이로 보이는 어두운 내부 프레임 층이 얇다.
- 다리가 아직 약간 블록스럽다.

## 주의
- 로블록스 반입 경로(GLB + 팔레트 UV) 아직 없음. 삼각형 수는 문제 없음.

## 교훈
- 컨셉 재현은 "어느 방향에서 찍었나"부터 잰다. 카메라가 틀리면 형태를 아무리 고쳐도 안 닮는다.
- 안테나 기울기 부호 하나로 V ↔ X가 뒤집힌다. 머리는 크롭 렌더로 따로 확인.
- 풀 모델 고해상도 렌더는 OOM → 크롭 또는 파츠 부분 렌더.

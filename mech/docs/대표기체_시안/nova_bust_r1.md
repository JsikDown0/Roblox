# NOVA 흉상 r1 — 시안 1 메인 디자인 재현 (2026-10-25)

GPT 시안 "시안 1 | 메인 디자인(샤프 & 화려한 느낌)" 1행(front / 3/4 / side / back)을 복셀로 재현. 머리는 시안 그대로(V핀·이마 센서·사선 눈·V 마스크) — 유저 결정.

## 방식 — 블록 → 복셀 굽기 → 복셀 레이트레이서
- `bm.py`: blockmesh 확장. 블록에 mode(add / cut / paint) 추가 → 복셀화 때 비우기·색칠.
- `vox.py`: 블록(볼록 다면체)을 격자에 굽는다. 칸 중심이 블록 안(+0.25칸 부풀림)이면 포함. 최종 vs=1.25 → 146×85×136, 38만 칸, 표면 5.9만 칸. 섬 1개(떠 있는 조각 없음).
- `vrt.py`: numba DDA 레이트레이서. 조명을 '복셀 면' 단위로 미리 구움(중거리 AO 64광선, 발광 빛 번짐 32샘플 + 가림 판정) → 노이즈 없음. 픽셀은 그림자 2광선 + 꼭짓점 AO + 하이라이트. 블룸·ACES. 4뷰 ss=2 약 7초, 최종(ss=3) 약 60초.
- `cmp_bust.py`: 시안 크롭과 같은 구도로 비교(views / one OUT VIEW / head). 시안 이미지는 `ref.png` 로 같은 폴더에. `final_bust.py`: 최종 시트 4종.
- 기체 정의: `대표기체_시안/nova_bust_r1.py` → 실행 시 `bust.py` 로 이름 바꿀 것.

## 측정값(시안 정면 크롭 5px = 1단위)
- 폭: 어깨 ±80~90, 가슴 ±44, 아랫배 ±25~35(아래로 좁아짐). 머리 ±20(귀·안테나 ±27). 핀 끝 (±46, z150).
- 어깨 정면 실루엣: 위가 넓고 아래가 좁은 역사다리꼴(z91 37~81 → z61 51~78). 정점은 바깥-가운데.
- 측면: 가슴이 얼굴보다 약 10 앞으로 나옴, 어깨는 뒤쪽. 날개는 후면 기준 수직에서 약 20°.
- 카메라: front yaw0 pitch11 / 3/4 yaw38 pitch14 / side yaw90 / back yaw180, fov 36.
- 시안 뷰끼리 안 맞는 곳(정면은 날개 하나·측면 핀 끝 깊이)은 다수 뷰를 따름.

## 교훈
- 큰 면은 축 정렬 판을 계단식으로 물리는 게 맞다. 판 자체를 돌리면 계단 줄무늬(꼭짓점 AO가 홈마다 어두움)가 생겨 지저분해진다. 회전은 핀·날개처럼 얇은 것만.
- 모서리 무작위 깎기(chip)는 점박이 구멍이 돼서 폐기.
- 어두운 상자가 발광 띠 앞을 가리는 실수(슬릿) — 발광은 짙은 홈보다 앞에 둔다.
- 가슴이 '벽'처럼 보이면: 흉판 윗선이 바깥으로 크게 올라가야(V 넥) 하고, 코어는 흉판보다 10 뒤로.

## 남은 차이
- 시안의 각지고 조각적인 판 형태(쐐기·비스듬한 면)보다 블록감이 강하다.
- 어깨가 시안보다 상자형, 3/4 뷰에서 시안은 더 낮고 넓게 퍼져 보인다.
- 로블록스 반입(복셀 → 그리디 메시 GLB) 경로 아직 없음.

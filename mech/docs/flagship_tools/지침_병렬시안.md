[대표 기체 시안 작업 지침 — 이 방 담당 방향: ______ ]
(빈칸에 한 줄: 예) 가는 고기동형 / 중장갑형 / 기사형. 비우면 스스로 하나 정해 보고 맨 위에 밝힐 것)

목표: 로봇 게임(Roblox PlaceId 127133285131400 "Mech")의 대표·마스코트 기체 복셀 디자인 시안 1개를 약 30분 안에 만들어 렌더 시트로 보여 준다. Blender·Roblox Studio 는 쓰지 않는다(작업 공간 Python 만). 중간에 질문하지 말고 끝까지 진행하고, 판단한 것은 보고에 적는다.

1. 도구 가져오기
- 프로젝트 문서 `claude/로봇차기작/flagship_tools/` 의 flag_vox.py · vox_preview.py · check_model.py · flagship_build_r1.py 를 project_read 로 읽어 작업 폴더에 같은 이름의 파일로 저장한다(numpy·scipy·matplotlib·PIL 필요, 없으면 pip install --break-system-packages).
- flag_vox.py = 엔진: 파트별 uint8 배열, 마스크 box/cbox(모따기 상자)/poly/slab/cyl/ell, add/cut/paint/paint_s/groove/emboss, M.mirror, part.rot(기울기), M.blocks(pose=).
- vox_preview.py = 렌더러: render(blocks, palette, emissive, yaw, pitch, ppc, ss, ao_amt) · sheet(images, labels).
- flagship_build_r1.py = 앞서 만든 시안. 코드 쓰는 법만 참고하고 디자인은 따라 하지 않는다.
- 새 빌더 파일 이름은 `flagship_<방향영문>_<HHMM>.py`, build_all() 이 Model 을 돌려주게 만든다.

2. 규격(나중에 리깅을 붙일 수 있게)
- 칸 = 0.05 Blender. +X = 기체 왼쪽 · −Y = 정면 · +Z = 위 · 바닥 z=0. 칸 i 의 중심 = 정수 i, 좌우 대칭은 i → −i.
- 머리 꼭대기 약 260칸(프로토의 1.2배, 인게임 약 32스터드). 날개·안테나는 그 위로 나가도 된다.
- 파트 이름: Pelvis(뿌리) · Torso · Head · ShoulderL/R(견갑) · UpperArmL/R · LowerArmL/R(손 포함) · UpperLegL/R · LowerLegL/R · FootL/R · Backpack (+ 필요하면 Wing·Skirt 등 추가). 피벗 = 관절 위치(칸 단위), 부모를 지정한다. 왼쪽(L)을 만들고 M.mirror 로 오른쪽(R).
- 색 번호 뜻: 1 주장갑 2 보조장갑 3 프레임 4 검정(홈) 5 강조 6 발광 7 금속.

3. 렌더·자체 검토(최소 3바퀴)
- 전체 4면: yaw 0 정면 · 30 3/4 · 90 옆 · 150 뒤, ppc 2.6~2.9, ss 2, ao_amt 0.4 → sheet. 한 장 약 15초.
- 상체 근접은 볼 파트만 골라(M.blocks(skip=...)) ppc 6~8. 전체를 ppc 9 로 그리면 메모리 초과로 죽는다.
- 매 바퀴 자문: 이 방 담당 방향이 실루엣만으로 드러나나 / 200px 로 줄여도 읽히나.
- `python3 check_model.py <모듈이름>` → 파트당 삼각형 1만 미만, 섬 0 이어야 끝.

4. 산출물(파일 이름은 방마다 안 겹치게 방향 + 시각)
- `flagship_<방향>_<HHMM>_views.png`(4면) + `_colors.png`(3/4 뷰 색 3종) → SendUserFile 로 보여 준다.
- PC 가 연결돼 있으면 device_commit_files 로 `C:\Users\<you>\Downloads\Mech_Basic_Roblox\_preview\`(PNG)와 `...\_scripts\flagship\`(빌더 .py + M.save 한 json). 연결이 없으면 건너뛴다.
- 프로젝트 문서 `claude/로봇차기작/대표기체_시안/<방향>_<HHMM>.md` 에 짧은 메모(콘셉트 3줄 · 비율 수치 · 삼각형 · 파일 경로). `현재상태_*.md` 는 고치지 않는다(여러 방이 동시에 쓰면 충돌).

5. 색 3종은 방향에 맞게 자유롭게 정한다. 발광은 6번 색만.

6. 보고(짧게, 한국어): 콘셉트 한 줄 · 특징 3개 · 스스로 본 약점 1~2개 · 파일 위치.

7. (선택) 더 높은 품질이 필요하면 흉상 파이프라인을 쓴다: `flagship_tools/` 의 bm.py(블록 모델러 + cut/paint) · vox.py(블록 → 복셀 굽기) · vrt.py(복셀 레이트레이서, 발광 빛 번짐·AO) — 사용 예는 `대표기체_시안/nova_bust_r1.md`. numba 필요(pip install --break-system-packages numba).

## 1. 게임 모드 — 4:4 거점전 `[결정 11-02]`
- 주 모드 = **4:4 거점전**(빈자리는 봇). 1:1·2:2 는 주 모드로 하지 않는다.
- 이유(유저): 메카 1:1·2:2 는 건담 버서스 인식이 강해 열화판으로 보일 위험 + 그쪽은 가드·부스트 캔슬 같은 격겜식 시스템이 더 필요. 팀 거점전이 메카 장르 주류(워로봇·메크 아레나·배토2 등, 처음 레퍼런스도 전부 팀전).
- 따라서 버서스식 **코스트 게이지(3000/2500…)는 쓰지 않는다** → 거점 점수 + 리스폰 대기로 대체 `[판단]`.
- 성능 `[실측: mech/studio/stress/README.md]`: 갤럭시 S22 에서 기체 8대 GPU 약 11ms(예산 16.7ms 의 66%), 평균 60 FPS. 4:4 가능. 중저가 기기 대응 = 그림자 축소(−15~20%) + 겹친 면 제거·LOD(삼각형, −25~30% 상한). 재질(SurfaceAppearance)은 영향 없음.

## 2. 수익·해금 `[결정 11-02]`
- 기체 해금 = **뽑기 또는 구매**(캡슐온라인·배틀 오퍼레이션식).
- **성급 최대 3성**. 높은 성급은 페널티(예: 부활 대기 길어짐).
- 아직 정할 것 `[제안]`: 성급별 차이(체력·화력 vs 특화만) · 팀 코스트 상한(성급 합계) · 지금 4기의 성급 · 무료 기본 기체(역할마다 1기) · 천장.
- 지킬 것: 로블록스 유료 랜덤 아이템 = 구매 전 확률 공개, `PolicyService:GetPolicyInfoForPlayerAsync().ArePaidRandomItemsRestricted` 인 유저에겐 뽑기 대신 직접 구매만. 한국 확률형 아이템 규제 적용 여부는 미확인 → 확률 공개 권장.
- 기체 수: 같은 몸 + 무장·색·부품만 바꾼 **바리에이션**으로 수를 늘린다 `[제안]`(예: FELSEN 지휘관형).

## 3. 출시 로스터 `[제안]`
- 4:4 에서 겹침이 덜 느껴지려면 출시 6기(지금 4 + 탱커 1 + 지원 1) + **같은 팀 같은 기체 1대 제한**, 이후 월 1기로 8기.
- 계산 근거: 무작위 선택이면 기체 12기여도 우리 팀 4명이 전부 다를 확률 57% — 기체 수보다 중복 제한 규칙이 체감에 크다.

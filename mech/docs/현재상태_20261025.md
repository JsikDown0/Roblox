## 1. 설계 논의와 결정

### 1-1. 피격 — 층 구분 `[결정 10-24]`
| 층 | 어디 맞든 같음 | 맞은 부위 따라감 |
|---|---|---|
| 체력·경직 수치 | ✅ (부위 파괴 없음) | |
| 불꽃·파편·장갑 조각 | | ✅ 맞은 자리 |
| 몸 전체 반응(움찔·경직 동작) | ✅ 무기·누적치가 정함 | |
| 손상 외형 | 언제(체력 단계) | 어디(많이 맞은 곳부터) `[제안]` |
- 맞은 자리 연출은 월드 좌표가 아니라 **맞은 파트 + 파트 기준 위치**로 보낸다 `[제안]`.
- 근거 `[조사]`: 건담 버서스·아머드 코어 6 모두 체력 하나 + 경직 체계, 부위 파괴 없음. 부위 파괴는 PvE 보스 약점에만 붙일 수 있음.

### 1-2. 원거리 판정 `[제안, 미확정]`
- `[실측]` 서버가 보는 휴식 자세에서 총구가 발바닥보다 약 4스터드 아래(바닥 속). 화면 총구와 약 20스터드 차이. 지금 서버는 이 총구에서 레이를 쏜다 → 낮은 엄폐물에 막힐 수 있음.
- 제안: 사수 클라가 화면 기준으로 판정 → 서버는 연사 간격·원점 거리·대상 위치 허용 오차·벽·사거리만 검사.
- 다른 클라 예광탄은 화면 총구에서 그리도록 고침(구현).

### 1-3. 경직 방식 — 무기 확장과 엮어 논의 중
- 건담 버서스(다운치 누적) vs 아머드 코어 6(충격 → ACS 게이지 → 스태거 + 직격 보정) `[조사]`.
- 추천 `[제안]`: 충격 게이지 뼈대 + 근접 마지막 타 다운(다운 중 무적). 몰매 차단 장치 필수(무쌍 선례). 상태는 끝나는 시각 속성 하나.
- 무기 역할 안 `[제안]`: 라이플 = 견제·지속 / 빔 = 경직 여는 한 방 / 미사일 = 회피 강요 / 근접 = 경직 뒤 마무리.

### 1-4. 조작·밸런스 결정 (10-25)
- 근접은 보조무기. 빔사벨 DPS 는 라이플 아래로 `[결정]` (5절 DPS).
- 근접 내딛기는 적 쪽으로 끌려가는 보정 없이 짧게 `[결정]`.
- 점프는 기본 점프 + 쿨만 `[결정]` — 누르면 바로 뜬다(입력 지연 없음).
- 장전 중 무장을 바꾸면 장전 취소 `[결정]` (처음엔 "바꿔도 계속" 이었음).
- 2단 점프는 막는다 `[결정]`. 점프 어색함 분석 뒤 안 1(공중 자세 섞기)·2(체공 비례 착지) 채택 → 이어서 **안 3(중력·점프력) 채택, 수치는 Claude 추천대로** `[결정 10-25 오전]` → 플레이 뒤 **"점프 체공과 높이를 대폭 늘리자"** `[결정 11:04]` → **"힘을 모으는 시간을 0.4초 정도로, 대신 높이·체공도 약간 더"** `[결정 11:10]`.
- **빔사벨 휘두르는 속도를 좀 늦추자** `[결정 11:04]` → 25% (SaberSlow 1.25). 쿨다운은 그대로.
- **줌** `[결정 11:14]`: 오른쪽 클릭. 저격총을 따로 출시할 예정이라 **저격급 배율은 금지, 시야를 조금 확대한 라이플 정도**. 줌 동안 **양팔 사격 자세**.

## 8. 작업 메모 (교훈)
- **복셀 경사는 1:1·1:2 같은 정수 비율로, 비스듬한 큰 판은 세워 만들고 관절로 기울인다**(10-25 대표 기체): 임의 기울기(다각형 실루엣)는 계단이 불규칙해 잔 줄무늬 소음이 되고, 기울인 날개 끝 1:2.8 은 톱니로 보였다. 날개·스커트·견갑은 똑바로 만들어 관절 회전(rot)으로 기울이면 메시째 돌아가 계단이 안 생긴다(Aero 엔진과 같은 방식).
- **가슴에 좌우 한 쌍(흡기·등) + 가운데 코어 = 얼굴**(10-25 대표 기체에서 재발): Aero 때 고친 형태를 또 밟았다. 가슴 장식은 가운데 한 줄만. 얼굴 아래 넓은 검정판도 "벌린 입"으로 읽혀 회색으로.
- **디자인 반복은 컨테이너 미리보기 렌더러로**(vox_preview.py: numpy 점 찍기 + z버퍼, AO·그림자·발광 번짐, 회전 파트 지원): 4면 한 장 약 15초, PC 왕복 없음. 큰 배율(ppc 9)로 전체를 그리면 메모리 초과 → 볼 파트만 골라 그린다.
- **복셀 섬 검사**(ndimage.label, 파트별 연결 성분 1개): 모따기로 좁아진 몸통 옆에 붙인 살대가 공중에 떠 있었고, 계단 안테나는 대각선으로만 닿아 끊겼다.
- **메시만 바꿀 땐 `MeshPart:ApplyMesh(src)`**(10-25 Aero, 에디트 MCP 에서 동작): 인스턴스가 그대로라 관절·용접·Attachment 참조가 안 끊긴다. 그다음 Size = MeshSize×2, 위치를 바꿨으면 관절 양 끝·Attachment 를 "월드 위치 보존" 식으로 다시 쓴다.
- execute_luau 출력에서 `string.sub` 로 한글 줄을 자르면 UTF-8 이 깨져 **플러그인이 응답 시간 초과**로만 보인다(10-25). 출력 전에 `gsub("[\128-\255]","")` 로 비ASCII 를 빼거나 자르지 말 것.
- 기능을 "종류 둘" 로 늘릴 땐 코드를 복제하지 말고 **구조물 속성 묶음 + 기체 속성 하나(LaunchSite)** 로 고른다(10-25 사출 두 종류): 땅굴 값은 속성이 없을 때의 기본값으로 남겨 옛 기체·옛 구조물이 그대로 돈다.
- **새 장착물(엔진·포드 등) 자리는 동작 스윕으로 정한다**(10-25 Aero): 팔이 쓰는 공간은 눈으로 안 보인다. 자세표 + 관절 틀을 Studio 에서 숫자로 뽑아 파이썬에서 실제 복셀을 모든 동작 중간까지 돌리면 "어디가 비었나" 가 칸 단위로 나온다. 첫 상자 근사(프로토 팔 경계 상자)는 어깨 장갑 폭 때문에 과하게 막혀 보였다 → 실제 새 팔 복셀로 다시. 장착물이 걸리는 동작은 대개 "등에서 꺼내기/넣기" 같은 수납 동작이라, 수납 자리를 바꾸는 게 장착물을 멀리 빼는 것보다 싸다.

## 2. 확정 구조 — 허브·스포크 동심원 `[결정 2026-09-24]`

```
              [섬]
        [섬]   |   [섬]
            \  |  /
   [섬] ———— (매장) ———— [섬]
            /  |  \
        [섬]   |   [섬]
              [섬]
   섬 8칸이 모두 매장에서 같은 거리(반지름 R). 다리는 섬마다 1개.
```

원 위의 점은 중심에서 모두 같은 거리 → **매장을 정중앙에 두면 동선 공평이 구조로 보장된다.**
단, 아틀란티스 원본 그대로면 세 군데서 다시 깨진다. 그래서 바꾼 것:

| 원본 | 바꾼 것 | 이유 |
|---|---|---|
| 땅 고리 2개 | **섬은 한 고리에만** | 두 고리에 다 섬을 두면 바깥 고리가 멀어져 문제가 돌아온다 |
| 방사형 다리 몇 개 | **섬마다 다리 1개** | 다리 사이 섬은 고리를 돌아가야 해서 위치마다 거리가 달라진다 |
| 휘어진 고리 땅 | **따로 떨어진 네모 섬** | 휜 땅에는 3.0 정사각 키캡 격자가 안 맞는다 (v5 1-4 "키캡 한 칸(3.0)"). 사진 스타일과도 그대로 맞물림 |

추가 규칙:
- 섬은 **긴 변을 바깥으로** 둔다 → 섬을 키워도 걷는 거리가 안 는다
- 인원 **6~8명** `[결정]` → **8칸 고정, 6명 서버는 2칸 비움** `[제안]`
- ❌ **걸어 다닐 수 있는 "공용 통로 고리"는 뺐다** — 처음엔 내가 제안했으나, 섬끼리 옆으로 건너는 지름길이 된다. 그러면 나중에 한 곳에 시설을 추가하는 순간 가까운 섬이 생긴다(3절). 고리를 둔다면 **보기만 하는 장식**이거나 **다리가 지나는 구간만** 밟히게.
  - v5 3절 "통로 이벤트" 는 **다리 8개에 똑같이** 걸면 공평이 유지된다.

### 2-1. 치수 `[계산]`

```

### 2-2. 높이 — 그릇 모양 `[제안 · 미확정]`

```

## 3. 증축 규칙 — "얼마나 자주 가는 곳인가" 로 자리가 갈린다 `[결정: 구조와 함께 채택]`

| 종류 | 자리 | 이유 |
|---|---|---|
| **자주 가는 곳** (매장·공급처 추가) | **가운데에 위/아래로 층** | 모든 섬과 거리가 같은 점은 중앙 하나뿐. 계단·엘리베이터도 중앙에 하나 |
| **섬마다 필요한 것** | **섬 뒤 같은 자리에 8개 복제** | 거리 문제가 애초에 없다. 모델 하나 복제 |
| **가끔 가는 곳** (스킨 상점·순위판·퀘스트 NPC) | **바깥 띠 아무 데** | 반복 동선이 아니라 몇 초 차이는 불리함이 아니다 `[추측]` |
| **하나뿐인 이벤트 섬** | **바깥에 띄우되 다리는 매장으로만** | 모든 길이 중앙을 지나면 "내 섬 → 매장 → 이벤트 섬" 이 모두 같다. 뜨는 방향은 이벤트마다 돌린다 |

- 사용자 예시 *"이벤트로 옆쪽 섬이 떠올랐다"*: 모두에게 주려면 **섬 뒤 복제형(8개 동시에 솟음)**, 하나만 띄우려면 **중앙 연결형**.
- 중앙 연결형의 전제 두 개: ① 섬끼리 옆으로 건너는 길이 없을 것(2절 ❌ 항목) ② 섬 사이 틈을 점프로 못 건널 것(2-1).

**지금 비워 둘 것**: 중앙 위쪽(높이 제한 없이) · 섬 뒤 복제 자리 · 섬 고리 바깥 띠. 이것만 지키면 나중에 뭘 넣어도 구조를 안 뜯는다.

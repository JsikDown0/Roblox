### 0-4. 고칠 것 ② — `ReplicatedStorage.PropPlay` `[작성 · 미적용]`

**소품마다 Heartbeat 를 거는 `ensureLoop` 를 없애고, 전체를 도는 상주 드라이버 하나로 바꾼다.**

모듈 상단에 추가:
```lua
local active = {}    -- [model]=true : 움직이는 중이거나 닫혀 있는 소품. 드라이버가 도는 대상
local STALE  = 0.50  -- 드라이버 맥박이 이만큼 끊기면 죽은 걸로 보고 되살린다
local driverConn, driverBeat = nil, 0
```

기존 `ensureLoop` 의 **루프 본문**을 함수로 뽑는다(연결·해제 코드는 뺀다):
```lua
-- 소품 하나를 한 프레임 민다. 다 열려서 더 돌 일이 없으면 true
local function stepOne(model, st, dt)
    if st.target == 1 and os.clock() - (st.lastPress or 0) > LEASE then
        st.target = 0
    end
    local tDown = math.max(model:GetAttribute("PressTime")  or 0.35, 0.01)
    local tUp   = math.max(model:GetAttribute("ReturnTime") or 0.28, 0.01)
    if st.f < st.target then
        st.f = math.min(st.target, st.f + dt / tDown)
    elseif st.f > st.target then
        st.f = math.max(st.target, st.f - dt / tUp)
    end
    st.poseAt(smooth(st.f))
    if st.f >= 1 then
        if not st.didSound then playSound(st, model); st.didSound = true end
    elseif st.f <= 0.15 then
        st.didSound = false
    end
    return st.f == 0 and st.target == 0
end
```

드라이버와 생존 보장:
```lua
function M.start()
    if driverConn then return false end
    driverBeat = os.clock()
    driverConn = RunService.Heartbeat:Connect(function(dt)
        driverBeat = os.clock()
        for model in pairs(active) do
            local st = state[model]
            if not st or not model.Parent or not st.parts[1] or not st.parts[1].Parent then
                active[model] = nil
                state[model]  = nil
            elseif stepOne(model, st, dt) then
                active[model] = nil          -- 다 열렸다. 다시 밟을 때까지 비용 0
            end
        end
    end)
    return true
end

-- 주인이 죽어 맥박이 끊기면 여기서 되살린다 = 주인이 누구든 결과를 보장한다
local function keepDriver()
    if driverConn and os.clock() - driverBeat <= STALE then return end
    if driverConn then driverConn:Disconnect() driverConn = nil end
    M.start()
end
```

`press` / `release` 는 `ensureLoop` 대신 `active` 등록 + `keepDriver()`:
```lua
function M.press(model)
    if not model or not model.Parent then return end
    local st = ensure(model)
    if not st then return end
    st.lastPress = os.clock()
    st.target = 1
    active[model] = true
    keepDriver()
end

function M.release(model)
    if not model then return end
    local st = state[model]
    if not st then return end
    st.target = 0
    if st.f > 0 then active[model] = true; keepDriver() end
end
```

곁다리 이득 둘:
- `playSound` 의 `task.delay`(소리 꼬리 자르기)도 드라이버 스레드 소유가 된다 → 사망해도 회수 안 됨
- Heartbeat 연결이 소품 수만큼이 아니라 **하나**

✅ **`_KeyWalk` 는 고칠 게 없다.** `press`/`release` 시그니처가 그대로다.
✅ 적용 후 `loadstring` 컴파일 검증 → `PropFactory.build()` → 0-2 의 반증 테스트.

## 5. 작업 방식 — 이번 세션 자기 점검 `[경험]`

**5-1. 원인을 세 번 추측으로 단정했다.**
`conn=false` 를 보고 ① 샌드박스 회수 ② 모듈 캐시 ③ 경쟁 상태 를 차례로 단정했는데,
실제 원인은 **`_Props` 가 통째로 갈려서 `m` 이 죽은 참조였던 것**이었다(1-7 ④).
✅ 인계의 *"이걸 반증할 관측이 내 손에 있나"* 를 세 번 다 건너뛰었다. 계측을 먼저 넣었어야 했다.

**5-2. 측정이 설계를 바꿨다.**
"밟으면 눌린다" 를 다 만들고 나서야 **밟는 면이 Y=4.57 이라 걸어서는 못 올라간다**는 걸 쟀다(1-4).
✅ 인계의 *"값은 추측하지 말고 측정"* — 동작을 짜기 전에 **닿는지부터** 쟀어야 했다.

**5-3. 인계문서에 근거 없는 서술이 섞인다는 지적** `[경험 2026-09-23]`
그래서 이 문서는 출처 태그를 `[실측]/[작성]/[기록]/[추측]` 로 쪼갰다.
✅ **다음 세션도 이 규칙을 유지할 것.** 특히 Studio 미연결 상태에서 쓸 땐 `[기록]` 을 `[실측]` 으로 승격시키지 말 것.

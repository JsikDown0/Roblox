## 2. 먹기
빵 · 마시멜로를 밟으면 찍으러 감(1.52초) → 백팩에 도구 → 클릭 = 한 입(0.8초 간격 · 3번) → 돈 · 도구 사라짐. 자리 음식은 찍기 뒤 3초 후 복귀.
도구는 왼손에 직접 붙인다 (`RequiresHandle=false` · LeftGrip) — 기본 손잡이는 오른손 고정.
모션은 **코드로 계산**: 팔꿈치로 거리를 맞추고 어깨로 음식을 입에 향하게 한다. 업로드 없음. 입 위치 = `PropPlayFondue` `MOUTH_X · Y · Z`. 샌드웨이퍼 "이제 맞는다".
실제 아바타 관절은 **AnimationConstraint** 다 `[F5 11-05 로그]` — Motor6D 만 찾으면 조용히 안 움직인다. Transform 은 Stepped 에서 쓴다. 다른 기능에서 관절을 만질 때도 같다.
샌드웨이퍼가 만든 애니(R15_Eating_V2 · R6_Eating)는 막대 길이 문제로 안 쓴다. R6 애니는 키프레임 0으로 읽혔다.

## 3. 엔진에서 잰 것
- `SpecialMesh` Sphere 는 텍스처를 그리지 않고, TextureId 를 넣으면 MeshType 이 FileMesh 로 바뀌어 작은 큐브가 된다.
- 왁스볼 메시 UV 는 꼬리 쪽에 몰려 있고 권한이 없어 읽을 수 없다. 이미지를 입힐 구는 `RS.PlanetMeshes` 반구 L · R (세로 = 위도).
- Beam 부착점은 **부모를 먼저 정한 뒤** WorldCFrame 을 쓴다 (돌아간 부모면 옆으로 눕는다). 곡선은 부착점 X 축을 따른다. 분수 흐름 = Beam 58개 + 이미지 `104481029061762` · 속도 0.65.
- execute_luau 두 번 실행을 이번에도 봤다. 복제한 바닥은 `GalleryWarp` 까지 따라오니 덮어쓴다.
- 업로드 도구는 인증 실패(`User not authenticated`) → 이미지는 샌드웨이퍼가 올리고 ID 를 준다. 데칼 → Image ID 변환, **에셋 이름으로 순서를 대조**한다 (11-04 에 2번째 · 4번째가 바뀌어 왔다).

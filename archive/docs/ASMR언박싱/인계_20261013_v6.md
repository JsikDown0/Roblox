## 1. 09-29 ~ 10-12 에 정해진 것 `[결정]`

### 1-1. 등급 · 상자
- 등급 사다리: **일반 → 레어 → 에픽 → 레전더리 → 신화 → 우주 → 갓**. 고급은 레어와 차이가 애매해서 뺐다. 레어 색은 초록.
- 심연(옛 '심해')은 사다리 **밖**으로 뺐다.
- 상한을 높이는 과장법(예: 신화 → 우주 → 갓)은 아이들한테 더 먹힌다고 봤다.
- 높은 등급일수록 무겁다 (크기는 꼭 비례하지 않음). **카트 무게(칸 수)는 상자 크기가 아니라 등급으로 정한다.**
- 상자 모델: **복셀풍 간결한 기본형**으로 확정 (등급은 색으로 강조. 레전더리·신화는 근엄하고 화려하게, 레어·에픽은 과하지 않게). 판타지 상자 · 판자 상자 · 택배 상자 시안은 기각.
- 선반에서 파는 상자 = 이 등급 상자. 골판지 택배 상자는 테스트용이었다. 등급 상자는 원래 크기 그대로 두고 선반 칸을 꽉 채우지 않는다.

### 1-2. 매장 구조
- **입구 8개 유지**: 1~2개로 줄이면 입구 가까운 집이 유리해진다.
- 그림: 거대한 창고형 매장에 들어서고 → 크기감에 압도되지만 비좁지 않고 → 랙에 올라가서 쇼핑하는 색다른 쇼핑 (일반 선반 쇼핑도 있음).
- 배치: A(전체 평행 랙)와 C(가운데 랙 덩어리 + 둘레 트인 홀)를 그레이박스로 비교한 뒤 **C로 결정**. 동서쪽 랙 추가는 꽉 차 보여 뺐다.
- 랙 높이 50 · 통로 30 (시험장에서 정함).
- 랙 오르기: 사다리(카트 잡기가 끊김)·계단은 기각 → **랙 양 끝 자동 리프트** 부활. 내려올 땐 정차 없이 빠르게. 랙에서 내려오는 기본 방법은 점프 (낙사 피해 없음). 엘리베이터는 쓰지 않는다.
- **지게차는 1층에서 뺐다 (10-13)**: 리프트를 넣고 보니 메리트가 없었다. 대형 화물 이벤트를 만들 때 그 전용으로 되살릴지 다시 정한다.
- 층 배치 계획 (2026-10, 구현은 나중):
  - 건물 층마다 큰 분류 1~2개 (예: 1층 말랑이·음식, 2층 문구·가전 느낌).
  - **랙 하나 = 세부 종류 하나, 랙 단 높이 = 등급.**
  - 랙 단 등급은 단마다 고정하지 않는다. 모든 단에 섞여 나오되 위 단일수록 높은 등급 비율이 크다. 그 층의 등급 범위는 넘지 않는다.
  - 1층 실배치를 먼저 하고 2층은 그다음. 위층은 1층 복붙이 아니라 약간 변형을 주고 싶다.

### 1-3. 선반
- **개인 선반** (10-09 재확인): 같은 칸이라도 사람마다 다른 상자, 가로채기 없음.
- 재입고: 칸에서 상자를 집으면 **그 칸이 N초 뒤 무조건 다시 채워진다** (계산 여부·겹침 무관).

### 1-4. 계산 · 도난 · 로봇 · 낮밤
- 입구마다 계산대 1대 + 더미 직원 1명, 문 안쪽에 도난 방지기.
- 계산 여부는 **길로 고른다**. 다가가기만 하면 계산되는 방식은 실수·이해 부족이 생긴다고 봐서, **계산 매트 위에서 멈추면 "계산할까요?" 확인 창**으로 본인이 정한다. 카트 위 미계산 상자에는 가격표.
- **뉴비 보호 3단계**: 첫 계산 전엔 훔치기 불가(밀어냄) → 첫 무단 퇴장 때 경고 1회 → 그 뒤 추격. 튜토리얼 설명에만 기대지 않고 규칙으로 막는다. 수배 등급(⭐)은 지금 넣지 않는다.
- 추격자 = 귀여운 보안 로봇. 잡으면 뿅망치로 넘어뜨리고 상품을 흡입해 회수 + 잠깐 래그돌. 상태별 표정. 화난 표정은 무서워 보여서 뒤집은 八 같은 간단한 기호로.
- 도둑 1명당 로봇 1대 + 로봇별 담당 구역 순찰 (한 명에게 몰리면 다른 쪽이 쉬워지는 걸 막음).
- 탈출 성공 = **내 섬 도착** (남의 섬은 인정 안 함). 미계산 상품을 다 버리면 추격 끝. 접속 종료 땐 서버가 회수.
- 로봇은 바다에서도 쫓는다. 도둑이 잠수하면 로봇도 수중 모드로 같은 깊이를 쫓는다.
- 래그돌에서 일어나면 카트가 자동으로 돌아온다.
- 추격 속도 16.5 시험 중 (과적 아니면 탈출 · 과적이면 잡힘).
- 낮·밤: 낮엔 훔치기 불가(밀어내기) — 낮에 문 앞에서 즉시 잡히면 밤에도 안 된다고 착각할 것 같아서. 낮엔 로봇이 충전 표시를 한 채 대기, 밤엔 직원과 교대 (밤엔 직원 없음 · 계산 불가).
- 밤 손전등: 로봇마다 앞쪽 부채꼴 시야. 미계산 상품을 실은 사람만 걸림. 짧은 예고 뒤 뿅망치 + 회수 + 매장 밖 퇴장(재입장 가능). 랙이 시야를 가린다.
- 랙마다 스캔봇 1대가 단을 차례로 훑는다. 바닥 순찰봇 · 입구 로봇도 유지.

### 1-5. 멀티플레이 (10-09)
- 서버 8명 = 섬 8칸. 1인 1카트 + **카트 부르기**. 카트는 주인만 잡는다.
- 섬 시설은 서버 시작 때 1번 섬을 원본으로 복사한다 (섬 꾸미기를 고려).
- **계산한 상자 = 산 사람 것**: 산 사람만 다시 실을 수 있고, 카트 밖에선 산 사람 얼굴·이름 꼬리표.

### 1-6. 바다
- 바다에 들어가면 상자를 쏟는 규칙은 넣지 않는다 (나중에 표류 상자 등을 넣을 수 있게).
- 기어오르기는 끄지 않는다. 물에서 섬으로 오르는 길은 부두 계단.
- 물에선 카트가 반쯤 잠겨 출렁이며 떠 온다. 물속 이동 속도 = 땅과 같음. 물에서 놓은 카트는 그 자리에 떠 있다.
- 쏟아져 바다에 들어간 상자: 버린 상자처럼 10초 떠 있다 사라지되, 그동안 주울 수 있고 남은 시간이 보인다.
- 내 섬의 잡초·꽃 같은 작은 장식은 충돌을 끄고, 바위는 충돌을 유지한다.

### 1-7. 매장 1층 실배치 (10-13)
- 종류당 물품 3개 (등급이 높을수록 희귀 물품이 잘 나옴).
- 물품 모델: "시제품이니 간단하게, 구분만 되면 되도록".
- 밟기: "시제품이니 최대한 간단하게" → 눌림 + 종류마다 다른 소리.
- 매장 통로 바닥: **구역별 테마 바닥**.

## 7. 기술 함정 추가분 (v5 4절 8-17에 이어서)

**8-18. Highlight는 대상이 비면 부모 전체를 칠한다** `[실측 10-13]`
부모가 workspace면 맵 전체가 칠해진다 (workspace는 Model의 하위 클래스 — 프로젝트 함정과 같은 형태). ✅ 대상이 없으면 `Enabled = false`.

**8-19. Studio 창이 뒤로 가면 FPS가 떨어진다** `[F5 10-13]`
같은 자리 51 → 창 밖 5초 동안 18. ✅ 성능을 잴 땐 창을 앞에 두고, `_PerfProbe`의 "⚠️ 창 밖" 표시가 찍힌 줄은 따로 본다.

**8-20. 그림자 실험 전에 그림자가 그려지고 있는지부터** `[F5 10-13]`
그림자 그리기 횟수(Stats `ShadowsDrawcallCount`)가 0이면 그림자를 꺼도 차이가 없다. 글자판 그리기 횟수(`UI3DDrawcallCount`)도 늘 0이라 측정에 못 쓴다.

**8-21. 한글을 바이트로 자르면 플러그인 연결이 끊긴다** `[실측 10-13]`
`execute_luau` 출력에서 `s:sub(1, n)`으로 한글 중간을 자르면 응답이 깨져 시간 초과 · 연결 끊김. ✅ `utf8.offset`으로 글자 단위로 자른다. 연결이 다시 붙으면 `_G` 도우미가 사라지니 다시 정의한다.

**8-22. `_CartSystem` 메인 청크 지역 변수 130 / 200** `[실측 10-13]`
새 블록은 `do … end` 또는 즉시 실행 함수 안에. `do` 블록 지역 변수는 밖에서 안 보인다. 숫자·상태는 `SHELF` 표에 둔다.

**8-23. 배열 중간의 nil은 ipairs를 거기서 멈춘다** `[코드 읽음 10-13]`
옛 조준 `{ cargoFolder, shelf, myShelf }`는 `_Cargo`가 아직 없으면 선반 상자까지 조준이 안 되는 구조였다. ✅ nil을 빼고 모은다 (`_KeyWalk capFolders`와 같은 형태).

**8-24. 밟는 소품은 `_Loot`에 넣지 않는다** `[코드 읽음 10-13]`
`_Loot`는 키캡 검색(MaxParts 12)에 들어가 소품 파트가 진짜 키캡을 밀어낸다. 소품은 `AsmrProp` 태그 + 아래 방향 레이로 폴더와 무관하게 잡힌다. `PropFactory.setup`은 **자리를 잡은 뒤** 부른다 (원자세 `RestCF`를 그 자리에서 기록).

**8-25. 상자 장소는 `CrateState`에 묻고, `CrateState`로만 옮긴다** `[작성 10-13]`
`OnCart`를 직접 쓰면 `where`가 어긋남을 보고 warn 한 번. 새 장소를 만들 땐 `PLACES`에 한 줄 + `LOADABLE` 여부 결정. 그 장소의 타이머는 "내 장소가 아니게 되면 손 뗀다" 형태로.

**8-26. 주석의 전제는 낡는다 — 보관 전에 소비처를 grep** `[실측 10-13]`
`_ScaleTestLifts` · `_ForkliftClient` 주석은 "시험장과 같이 지울 것"이었지만 실제로는 매장 지게차를 돌리고 있었다.

**8-27. 스트리밍이 켜져 있다** `[실측 10-13]`
`workspace.StreamingEnabled = true` → 클라 폴더(예: 매장 바닥 타일)가 늦게 들어올 수 있다. 처음에 못 찾아도 다시 찾는 구조로 (`_KeyWalk refreshLoot`).

### 8-5. 설계 미결 `[미결]`
1. **매장 안 조준점(FPS식)** — 고민 중. 3인칭 기본 카메라는 내 머리가 화면 가운데라 조준점이 머리 위에 겹친다 → 바뀐 화살표를 먼저 보고 정하기로 제안함
2. **물품 · 바닥 소리 에셋** — 지금은 엔진 내장음. 구역 · 종류별로 쓸 소리 ID
3. **밟기 수입** (내 섬 + 공용 바닥 배달 수당) — 아직 구현 없음. 돈은 시작 돈 500뿐
4. 경제 숫자 전부 (가격 · 재입고 · 수명) — 성장 단계 설계 때
5. **섬 물건 저장** — 출시 전 필수 (놓는 좌표는 섬 기준이라 다른 번호 섬을 받아도 되살릴 수 있게 짜 둠)
6. 배치 모드 (지금은 개봉하면 정해진 격자에 자동으로 놓임)
7. 발견 알림 (희귀 상자를 찾으면 모두가 봄 — 섬맵설계 v4 7-3 `[결정]`, 미구현 `[코드 읽음 10-13 — _CartSystem 개인 선반 블록 주석]`)
8. 2층 (1층 변형 · 분류 1~2개)
9. **훔치기 방향** — 짐 무게만으로 성공/실패가 거의 정해지는 지금 방식이 맞는지 확신 없음
10. **카트 성장** — 용량만 키우면 훔치기가 "최대 용량 +1~2개"로 고정되는 문제
11. 계산 0회 뉴비 처리 — 짧은 하루짜리 튜토리얼 안 (제안 상태)
12. 대형 화물 이벤트 (지게차를 그 전용으로 되살릴지)
13. 화면 글자 영어 기본 여부
14. `Wallet` 세션 잠금 없음 — 같은 계정이 두 서버에 있으면 나중 저장이 이긴다 (출시 전)
15. 실기기 성능 테스트 (6절)

### 2-1. PlanetGummyArt
- 종류 = 모델 속성 `PlanetType`: `Earth`(기본) · `EarthClear` · `Sun` · `BlackHole`. 겉면 색 함수 = 표 `SURF` (`M.SURF` 로 노출 — 에딧 미리보기에서 후보 무늬를 끼워 보는 용도).
- 겉면 그림 512×256. 픽셀은 종류마다 한 번만 계산하고, **붙일 때마다 새 EditableImage** 를 만든다 (6절 함정 1).
- 좌표: 앞(-Z) = 동경 `FRONT = 110` · 그림 u = 0 이 뒤(FRONT-180) → 자르는 면(X = 0)이 앞뒤 경선이라 반쪽마다 u 가 넘어가지 않는다.
- 반구 `M.hemi(side, double)`: NU 40 · NV 36. 원점 = 자른 면 가운데, 크기 (D/2, D, D), CFrame = 젤리 중심(두 반쪽 같은 CFrame). `double` = 안쪽 면도 넣음.
- 모델 속성으로 켜는 것:
  - `CapArt` = 단면 그림 원판(블랙홀 나선 은하)
  - `ShellTr` = 껍질 반투명(값 = Transparency) + 안쪽 면까지 그림 (투명 지구)
  - `CoreRatio` · `CoreColor` = 안에 빛나는 속 반구 (지금 쓰는 세트 없음 — 투명 지구에서 뺐다)
- 만든 파트는 전부 `Archivable = false`, 속성 `EarthHalfVis = side` (에딧에서 만들어도 장소 파일에 안 남는다).
- 태양은 반구를 `Neon` 으로 (그림이 그대로 보이며 빛남 `[실측 10-28]`).
- 태양 무늬 = 후보 A(붉은 태양: 잔 얼룩 + 밝은 주황 구름 + 검은 필라멘트), 무늬를 40° 돌려 둠 (6절 함정 7).

### 2-2. PropPlay 자르기 구역
- 타임라인 (CutTime 1.4 · CutRegen 3.5 기준):
  - 썰기 0 ~ 1.4초: 칼이 앞뒤로 썰며(`SAW_HZ 1.6` · `SAW_AMP 0.45`) 젤리 꼭대기에서 도마까지(이동 = 2R + 0.17) 내려간다. 젤리는 눌리고(`CUT_SQUISH 0.07`) 두 쪽이 조금씩 벌어진다(`CUT_WEDGE 4°`). 반 왕복마다 `CutTickSound`.
  - 다 썬 뒤: 0.35초에 30°까지 툭 벌어짐(`CUT_OPEN` · `CUT_ROLL`, 살짝 넘쳤다 돌아옴) → 유지 → 마지막 0.45초(`CUT_CLOSE`)에 다시 붙음. 칼은 0.35초(`BLADE_OUT`)에 빠지며 사라짐. `CutHitSound` + `CutSound` + `CutFxSound`.
- 흘러나오는 연출 = 모델 속성 `CutFx`:
  - `lava`(태양): 검붉은 테 + 밝은 주황 웅덩이 덩어리 7개(`LAVA_R 3.1` · `LAVA_GROW 0.9`) · 방울 9개 · 김 · 불빛 세짐
  - `water`(지구): 파란 물 웅덩이(Glass) · 물방울 · 물보라 · 물안개 · **나무 5그루**가 차례로 뿅(`TREE_POP 0.4`, 둥근 나무 · 뾰족한 나무). 앞(-Z)은 비워 둠 — 자르는 사람이 보는 쪽
  - `goldwater`(투명 지구): 금속 금(Foil) 테 + 빛나는 금(Neon) 속 · 금빛 물보라 · **금빛 나무**(Foil) · 도마 위로 금가루가 오름 · 불빛 세짐
  - `galaxy`(블랙홀): 반짝이 가루 폭발 · 성운 연기 · 속이 빈 충격파 고리(조각 24개, `GAL_RING_R 6.5` · `GAL_RING_T 0.6`) + **UFO**(속성 `CutSurprise` 파트, 0.15초 뒤 떠올라 빙글 돌다가 닫힐 때 가라앉음, `UFO_RISE 0.6`)
  - 팔레트는 표 `SPILL` 하나에 모여 있다 (lava · water · goldwater). 새 행성은 여기에 항목만 추가하면 된다.
- 연출 파트는 **내 화면에만** (`workspace.CurrentCamera.CutFx` 폴더, Archivable = false).
- 칼을 처음 쥐면 가방(Backpack) 기본 UI 를 숨긴다 (이 게임 도구가 칼 하나뿐이라).
- 에딧 검증용: `M.debugCut(m, ang, s, dy, dz, a, uh, ua)` · `M.debugCutFx(m, u, dt)` — 7절 절차를 꼭 따를 것.

### 2-3. CutBoard (서버)
- 0.1초마다: 도마 영역(`PropPlay.cutZoneHit` — 모델 축 기준 `CutZoneHalf` · `CutFloorY`) 안이고 카트를 잡고 있지 않으면(`CartHolding ~= true`) 칼 지급, 나가면 회수.
- 휘두름(Tool.Activated): 영역 · `CutReadyAt` 확인 → `CutAt = now + CutDelay(0.05)` · `CutReadyAt = CutAt + CutTime + CutRegen` → `Wallet.add(plr, PropPlay.cutReward(m))`. 써는 동안 손의 칼은 숨김(예약 delay 없이 tick 이 되살림).
- 자기 섬 세트 + (Studio 에서만) 갤러리 세트를 센다.

## 4. 이번 세션(10-28 ~ 10-30)에 한 일 `[작성 10-28]`
- 행성 그림 모듈 `PlanetGummyArt` (지구 · 태양 · 블랙홀 · 투명 지구) — `EarthGummyArt` 대체.
- PropPlay 자르기 연출: 천천히 썰기 → 용암 · 은하 · UFO → 용암을 `spillStep` 하나로 합치고 물 · 금빛 물 · 나무 추가.
- 태양: 무늬 1판(피자처럼 보임) → 2판 → 후보 A · B · C → A 확정 · 40° 회전. 속 층을 빨강 → 노랑으로.

## 6. 남은 일

### 6-1. 투명 지구 안에 구형의 무언가가 보임 (10-30, 최우선)
샌드웨이퍼: "안쪽이 아예 투명하게 안보여야". 화면을 아직 못 봤다. 의심 둘 `[추측]`:
1. **단면 원판** — 두 반쪽이 맞닿는 가운데에 반쪽마다 5장, 모두 10장이 반투명 Glass 로 늘 있다 → 닫힌 상태에서도 껍질 너머로 크기가 다른 동그라미가 겹쳐 보인다. "반원끼리 합쳐진 흔적"과 자리가 맞는다.
2. **껍질 안쪽 면** — `ShellTr` 이면 `hemi(side, true)` 로 안쪽 면까지 그린다(뒤쪽 대륙이 비쳐 보이라고 넣음) → 반대편 반구의 안쪽이 공 안의 공처럼 보일 수 있다.

순서: 하나씩 끄고 캡처해서 원인을 가른 뒤 고친다.
- 원판이면: `ShellTr` 세트만, 닫혀 있을 때(`ang`·`s` = 0) `CutSide` 원판을 숨기고 칼이 들어가 벌어지기 시작하면 원래 투명도로 보이게 (PropPlay `cutPose` 쪽, 쉴 때 투명도는 `cutEnsure` 에서 기록). 불투명 행성은 원판이 껍질에 가려서 그대로.
- 안쪽 면이면: `attach` 에서 `hemi(side, shellTr ~= nil)` → `hemi(side)`.
- 둘 다 아니면: `GummyCollider` · 반쪽 자리(`EarthHalf`) 파트 투명도, PointLight 를 확인.

## 7. 에딧에서 자르기 미리보기 — 절차와 함정 `[실측 10-28]`

1. **require 캐시**: 같은 플러그인 실행 안에서 `require(원본)` 은 처음 읽은 판을 계속 돌려준다. 새 코드를 보려면 원본을 `Clone()` → 옆에 두고 `require(복제)` → 복제 `Destroy()`.
2. **PropPlay 안의 PlanetGummyArt**: PropPlay 는 `ReplicatedStorage:WaitForChild("PlanetGummyArt")` 를 require 하므로 위 1번으로는 옛 판이 붙는다 → 한 번의 실행 안에서: 원본 이름을 `PlanetGummyArt__orig` 로 → `Archivable = false` 복제를 `PlanetGummyArt` 로 넣고 → PropPlay 복제를 require → 볼 세트마다 `debugCut(m)` 한 번(이때 attach 의 require 가 바로 일어남) → **복제 삭제 · 원본 이름 되돌리기**. 되돌리기는 pcall 밖에서 무조건.
3. **새 PropPlay 를 읽기 전**: 지금 쓰던 인스턴스로 `debugCutFx(m, nil)` · `debugCut(m)`(인자 없음 = 원자세) 해 두고, 그 세트의 `EarthHalfVis` 파트를 지운다. 안 그러면 원자세가 벌어진 모습으로 잡히거나 보이는 파트가 두 벌이 된다.
4. `debugCut(m, math.rad(30), 0, (2R+0.17)*0.4, 0, 0, uh, ua)` = 다 벌어진 장면, `debugCutFx(m, u, 0.03)` 를 u 를 늘려 가며 여러 번 불러야 방울이 떨어진다.
5. PropPlay 인스턴스마다 `CurrentCamera` 아래에 자기 `CutFx` 폴더를 만든다 → 끝나면 이름이 `CutFx` 인 폴더를 모두 지운다.
6. 마무리 확인: 단면 원판 |x| = 0.010 ~ 0.026(지구 · 태양 · 투명 지구) / 0.002(블랙홀), 보이는 칼 0, 보이는 UFO 0, `CutAt` 없음, `__` 로 시작하는 임시 모듈 · 파트 0.
7. 기다림이 있는 코드(그림 생성 · attach)는 `execute_luau` 가 print 없이 먼저 돌아온다 → 결과를 `_G` 에 담고 다음 호출에서 읽는다. 시간 초과로 같은 코드가 다시 돌 수 있으니 멱등하게.
8. F5 를 한 번 하면 에딧의 보이는 파트가 사라지고 `_G` 도 비워진다(플러그인이 다시 뜸). 에딧 화면에서 행성이 원판만 보이는 건 정상 — 인게임은 정상 `[F5 확인 10-28]`.
9. Studio 창이 뒤에 있으면 캡처가 하얗게 나온다. 플레이 테스트 뒤엔 MCP 플러그인 연결이 자주 끊긴다 → 플러그인 다시 켜기.

## 8. 엔진 사실 (이번에 잰 것) `[실측 10-28]`
1. EditableImage 하나를 여러 파트가 쓰다가 그 파트들이 모두 지워진 뒤 새 파트에 다시 붙이면 **검게** 나온다(픽셀은 멀쩡) → 붙일 때마다 새 이미지.
2. `AssetService:CreateAssetAsync` 는 "not available yet" → 런타임 생성.
3. EditableMesh 로 만든 MeshPart 는 원점을 다시 잡지 않는다(메시 원점 그대로).
4. **그림의 알파(투명)는 MeshPart 에서 비쳐 보이지 않았다** → 투명은 파트 Transparency 로.
5. **그림을 안 붙인 EditableMesh MeshPart 는 화면에 안 그려진다**(색 · 재질을 바꿔도) → 단색이라도 그림을 붙인다(`coreTexture`).
6. Neon MeshPart 에 그림을 붙여도 그림이 보이고 빛난다.
7. 반구 두 쪽의 무늬는 이음매에서 이어진다(줄무늬 시험 그림 좌우 픽셀 비교 · 표식 점 3개 제자리). 태양 A 에서 이음매처럼 보인 세로 띠는 무늬의 밝은 구름 → 무늬를 40° 돌리니 띠가 따라 움직였다.
8. Ball 모양 파트는 크기 세 값이 같아야 한다(나무 잎을 공으로 만들 때).
9. 세트 갤러리 바닥 `Platform_NewCandidates` = 중심 (715, 0, 678), 46 × 38 → x 692 ~ 738 · z 659 ~ 697. 빈자리를 찾을 땐 `GetPartBoundsInBox` 로 겹침부터 잰다.

### 산개 각도

```lua
local function botAngle(bot)
    local idx = bot:GetAttribute("BotIndex")
    if not idx then  -- 폴백: 이름 해시에도 황금각을 곱한다
        local h = 0
        for i = 1, #bot.Name do h = (h * 31 + bot.Name:byte(i)) % 360 end
        idx = h
    end
    return math.rad((idx * GOLDEN_ANGLE) % 360)
end
```

**왜 필요했나:** 이름 해시 `(h*31+byte)%360` 이 접두사 공유 때문에 1° 간격을 만들었다 —
11마리가 20° 스팬(r=4.8 에서 호 길이 1.68 stud)에 겹쳐 섰다. 09-09 링 분산도 그 전 존 분산도 **처음부터 no-op.**

**되돌리려면** `math.rad(h)` 를 그대로 반환.

### 분산 반경 — 존이 링보다 좋다

```
zoneOffset  r = min(존X, 존Z) × 0.5 × 0.55   → 존 40이면 ≈11
ring        r = ATTACK_RANGE × 0.8            → 4.8
```

**강타 박스 반폭이 5인데 링 최대 |X| 가 4.8** → 옆 탈출이 물리적으로 불가능, 후방 호(≈36%)로만 빠진다.
강타 명중 인원 `[로그]`: 존 분산 **5~6명** / 링 분산 **5~9명** (수정 전 10~11명 전원)

**ringR 은 올리지 않기로 결정.** 정지 허용치 2 stud 때문에 r=5.5 면 실제 위치가 3.5~7.5 로 흩어져
사거리 6 밖 봇이 생긴다. 그리고 `KILL_ROUND_CHANCE=0` 이라 링 분기는 왕좌 붕괴 후만 돈다 = 안 쓰는 경로.

## 10. 이 문서를 쓰는 사람에게

값을 고칠 때 **출처 태그를 같이 갱신하라.** `[미확인]` 을 확인했으면 `[코드]` 로 올리고,

값을 단정하기 전에 물어라 — **"이걸 반증할 수 있는 관측이 실제로 존재하는가."**
존재하지 않으면 그건 측정이 아니라 가정이다.

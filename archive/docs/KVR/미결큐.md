#### 측정 설계

**🔑 절대값이 아니라 상대 순위만 필요하다.** 목표가 "8종이 서로 비슷하게"이지 "절대 DPS = X"가 아니므로, **대조군(무기 없는 판)을 만들 필요가 없다.** 8종을 같은 조건에서 서로 비교하면 된다. 2단계 무기 지급을 끄는 수단이 없으므로 이게 유일한 길이기도 하다.

**고정 조건**
```
/botmode capture     점령 강제. 초당 타격이 가장 높고(1.40) 판 간 편차가 작다
/hw <무기>           히어로 4체 전원 단일 무기        ⚠️ F5 끄면 해제됨 [로그]
1단계 무행동          아이템·평타·강타 전부 금지 → 봇 10 유지 → HP 825
2단계 무저항          반격하면 봇이 죽어 분모가 바뀐다
```

⚠️ **왜 킹이 아무것도 안 하나:** 봇이 죽으면 그 판의 공격자 수가 줄어 무기 간 비교가 깨진다. 09-17 3판 중 2판에서 킹이 무행동인데도 봇이 1마리씩 죽었다 → **B-7 선행 필요**(아래).

**지표 (우선순위 순)**
```
1순위   킹 DPS = 킹 피해 / 2단계 길이       🔬 [K] 가 그대로 찍어준다
2순위   2단계 길이 (성문 붕괴 → 킹 사망)
3순위   킹 피해 / 회 (평균)                 불변식 감시 겸용, 아래 참조
```

⚠️ **판당 편차가 크다.** 09-17 3판(무기 랜덤, 같은 조건): DPS `27.0 / 21.2 / 21.3` = **편차 27%**. 2단계 길이는 `28.7 / 33.6 / 33.1` = 17%.
→ **무기당 2판으로는 못 가른다.** 먼저 1종을 3판 돌려 편차를 재고, 그 편차가 무기 간 차이보다 작은지 확인한 뒤 나머지를 진행할 것. 편차가 크면 판수를 늘리는 게 아니라 **조건을 더 묶어야** 한다(맵 고정 등).

**판 수 (축 결정에 따라)**
```
(다) 선택 시    고정 6종 × 3판  = 18
                비례 2종 × 3판  =  6      ← 825 조건만. 비례는 밴드가 따로니까
                                 합 24판 ≈ 45분

(가)/(나) 선택 시  전환 작업이 먼저. 전환 후 위와 동일
```

⚠️ **비례 2종의 HP 스케일 검증은 별도다.** 825 와 330 두 조건이 필요한데, 330 을 만들려면 1단계에서 봇 6마리를 잡아야 해서 "무행동" 프로토콜이 깨진다. `/killbots(/kb)` 로 대체 가능한지 **먼저 확인**할 것 — N마리 지정이 되는지, 전부 죽이는지 모른다 `[미확인]`.

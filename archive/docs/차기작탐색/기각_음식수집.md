고등급일수록 개봉 대기(스킵 과금) / 집에 배치해 수익 / 직원 자동화 / 환생.

### 🔴 이탈 원인 — 1차 자료 `[경험]`

**본인(이탈):** 같은 패턴 반복 + **박스 하나에 20~30분 이상 기다리는 게 싫었다**
**동생(10살, 계속 플레이):** **박스만 걸어두고 다른 게임 갔다가 까러 와서 조금 하고 또 떠남**
= **백그라운드 앱.** 지표로는 **재방문은 살고 세션이 죽은** 형태.

**교정 ① 긴 대기는 짜릿함 장치가 아니라 매출 장치다.** 구조만 보고 *대기 = 스포일러 = 짜릿함* 이라
단정했는데 **실제 값을 안 물었다.** → *값은 추측하지 말고 측정.*
**교정 ② 개봉은 세션 엔진이 아니다.** 개봉 후 할 일이 3초면 세션이 3초가 된다.

### ⚠️ 기대치 — 수집형은 원래 소진된다

평점 96.7%인데 6주 만에 97% 가 빠졌다. **싫어서가 아니라 다 해서 떠난 것.**
*"이미 승자가 있다"* 가 아니라 **"소진된 선구자가 있다"** 다.
→ **목표는 "붕괴 방지"가 아니라 소진까지의 길이 + 소진 후 바닥이다.**
⚠️ 주 1회를 돌리는 팀(Gakuran)도 4주 만에 92%, **Grow a Garden 은 피크의 0.16%** 까지 빠졌다.

## 3. 현재 설계

### 3-1. 🔴 세 개의 엔진

```
조리 (오프라인 · 시간 단위)   →  재방문 이유          D1 엔진
개봉 (실시간 · 초 단위)        →  접속 직후 보상       짜릿함 엔진
벨트 재료 수집 (5분 로테)      →  체류                세션 엔진   ← 핵심
```

**대기 시간의 임계** `[추측, 경험 기반]`

| 길이 | 유저 행동 | 성격 |
|---|---|---|
| 초 단위 (~30초) | 그 자리에서 기다린다 | 짜릿함 장치 |
| 분 단위 (20~30분) | 자리를 뜬다 | 매출 장치 + 이탈 장치 |

경계는 **"한 자리에서 기다릴 수 있는 시간" = 1분 미만.** 하위 등급 대기는 0초.
⚠️ **오프라인 진행이 "돌아올 이유"가 되려면 그 사이에 할 일이 있어야 한다.**

### 3-2. 🔴 루프를 닫는 것

**판정: "개봉만 하고 나가면 손해인가?"** 손해가 아니면 개봉만 하고 나간다.
✅ **"나가기 전에 오븐을 채운다"가 세션의 종료 조건.**
```
접속 → 개봉(보상) → 오븐이 비었다 → 벨트에서 재료(5분 로테 · 접시 3칸) → 채우고 나간다
```
⚠️ **오븐 슬롯 수가 곧 세션 길이다.** → **초기 슬롯 3~5, 과금은 그 위로.**
슬롯을 과금에 묶으면 **무과금 유저의 세션이 구조적으로 짧아지고 리텐션이 과금에 묶인다.**

### 3-3. 등급 모델 — 종류는 확정, 품질은 조합형 배수

요리 **종류**는 레시피를 맞추면 확정(컬렉션 칸이 채워진다). **품질**이 확률.
낮은 품질이 나와도 종류 칸은 채워진다 → **손실 없음 원칙 충족.**

🔴 **품질은 단일 등급이 아니라 조합형 배수로.** GaG 는 Gold × Rainbow × 날씨가 **곱해져** 1배~수천 배.
```
Unbox ASMR   희귀도 = 새 물건            → 다 모으면 끝 (6주)
GaG          희귀도 = 기존 것에 곱하는 배수  → 같은 씨앗을 계속 심을 이유
```
**컬렉션은 유한하지만 배수는 무한하다.** 9절 최대 빈칸의 최유력 답.

**확률을 움직이는 것이 2층 입력의 자리:** **재료 품질** · **조리 시간**.
⚠️ **과금은 확률에 손대지 않는다.** 과금은 개봉 스킵 · 슬롯 · 접시 칸 · 코스메틱.

### 3-4. 계단 갯수 — 5단, 문제는 갯수가 아니라 거리

단계 사이가 **최소 5~10배**. 기존 4단 + 최상단 1개 신설.
```
오븐 5개 · 하루 2회 접속 → 하루 10~20회 개봉 → 한 달 300~600회  [추측]
Legendary "한 달에 두세 번" → 약 1/150~1/300 / Mythic 을 1/5000 으로 두면 아무도 못 본다
```
⚠️ **Unbox ASMR 의 0.01% 를 베끼면 안 된다** — 탭 단위 + 자동화라 시도 횟수가 자릿수로 많다.
✅ **Mythic 을 확률이 아니라 조건으로.** "한 나라 세트를 전부 Legendary 로 모으면 열린다"
→ 저동접에서도 누군가는 보고, 클립이 나오고, 유료 랜덤 정책에서 자유롭다.

### 3-5. 연출 톤 — 같은 동작, 스케일만 다르게

**뚜껑 열기(cloche)를 외피로, 최상단만 신성으로.**
```
Common      뚜껑 슥 열림 · 소리 1개 · 로그 한 줄        대기 0초
Rare        조명 하나 · 색 팝업
Epic        무대 조명 · 카메라 줌 · 테두리
Legendary   뚜껑이 날아감 · 빛기둥 · 정지 1초 · 서버 알림
Mythic      화면 균열 · 전용 BGM · 전용 컷씬 · 서버 전체 알림
```
**떨림 길이 + 폭발 크기** 두 축으로만 갈린다 → KvR 의 *"예고·표식·판정은 같은 모양"* 과 같은 형태.
✅ **뚜껑 모델 1개면 회색박스가 돈다** = 모델링 약점 정면 회피.

### 3-6. 딸깍 문제 — 접시 용량

**접시 3칸 제한:** "이 칸을 상위 재료에 쓸까, 확실한 완제에 쓸까" = 2층 판단 자동 성립 /
칸이 차면 갖다 놔야 함 → 벨트 체류·집 왕복 리듬 / 손실 없음 유지.
⚠️ **판정: "숙련자가 매번 같은 선택을 하면 그건 선택이 아니다."**

### 3-7. 환생 — 축을 갈라야 한다

리셋: 코인 · 오븐 레벨 · 접시 칸 · 식당 규모 / **영구: 요리 도감(종류 · 품질 최고 기록)**
✅ Unbox ASMR 도 환생이 영구 속도 배수지 컬렉션 리셋이 아니다. 우선순위는 낮다.

### 3-8. 🔴 마찰 점검 — 층은 빼지 말고 순서대로 연다

GaG 의 22M 은 재미의 상한이 아니라 **진입 하한 0** 에서 나온 숫자다. 상세는 장르시장 메모 5절.

| 축 | 우리 | 판정 |
|---|---|---|
| 학습 | 재료→레시피→조리→품질 | ⚠️ "심고 기다린다"보다 층이 많다 |
| 기기 | 벨트 + 뷔페 홀 + 식당 + NPC 손님 | ⚠️ GaG 의 4인 정원보다 무겁다 |
| 스킬·시간·손실·사회 | E키 / 5분 / 없음 / 없어도 성립 | ✅ |

⚠️ **걸리는 두 개가 전부 이 세션에 추가한 것이다**(조리 층 · 사회층).
✅ **해법: 첫 10분은 GaG 만큼 단순하게, 층은 순서대로 연다.**
```
1분차   벨트에서 음식 집는다 → 집에 놓는다 → 돈 번다. 끝.
그 뒤    N개 모으면 조리 → 식당·손님 → 품질·세트·환생
```
⚠️ **튜토리얼이 아니라 점진적 해금이다.** 튜토리얼은 **설명**이고 해금은 **아직 없는 것**이다.

## 4. 🔴 사회층 — 저점을 만드는 것

### 4-1. 관측 `[경험]`

**Gakuran · Da Hood 는 표면이 PvP 인데 치고받는 사람은 거의 없고 대부분 서서 대화한다.**
✅ Gakuran 개발자가 설명문에 *"INTENDED Slice of Life"* 라 쓰고 "커뮤니티가 전투로 간다"고 덧붙였다.
```
시끄러운 소수(전투·희귀 뽑기) → 클립 → 신규 유입     = 마케팅 엔진
조용한 다수(서서 대화)        → 눌러앉음            = 저점 엔진
```
**PvP 는 콘텐츠가 아니라 같은 방에 모일 구실이다.**
⚠️ **Da Hood 의 저점은 7년짜리다** — 출시 기능이 아니라 장기 베팅. 그래도 **인프라는 1일차에.**
⚠️ **유일한 길도 아니다** — GaG 는 4인 서버로 사회층을 포기하고 유입 폭으로 저점을 샀다.

### 4-2. 사회 공간의 조건 넷 — 채점

| 조건 | 우리 |
|---|---|
| 모이는 장소 | ✅ 공용 뷔페 홀 — 유일한 공유 공간 |

⚠️ **로테이션 공백을 "체류 낭비"로 읽고 없애면 안 된다.** 그 공백이 사회층의 자리다.

### 4-3. 🔴 최대 구멍 — 컬렉션이 집에 있어서 광장에서 안 보인다

Da Hood 는 총·옷·현금, Gakuran 은 교복·헤어·스타일이 **한눈에 읽힌다.** 우리는 안 읽힌다 → 대화 재료 0.
✅ **정체성을 밖으로:** 들고 다니는 **접시 위의 요리** / **셰프 복장·칭호가 컬렉션 진행의 함수** /
개봉 등급이 잠깐 몸에 붙는 표식.

### 4-4. 병철이네 · 컨베이어 스시가 고치는 것 `[경험]`

🔴 전에 *"음식은 감각을 내장하지 않으니 NPC 손님이 필수"* 라 썼는데 **반응체가 다른 플레이어여도 된다.**
음식의 감각은 촉감이 아니라 **같이 먹는 의식**이다.
```
NPC 손님 = 하한 (혼자여도 식당이 돈다)   |   유저 손님 = 상한
```
✅ **거의 공짜다.** 음식 모델은 컬렉션 때문에 어차피 필요하고 먹는 모션 1~2개면 된다.

### 4-5. "치고받기"의 자리는 개봉이 대신한다

✅ **뷔페 홀에 시식대**를 두고 거기서 열면 **관객 보너스**. 동접 있으면 켜지고 없으면 집에서 연다.
→ Mythic 서버 알림이 **광장에서 터지는 사건**이 된다.

## 5. 🔴 포지셔닝 — "차별성 vs 보편성"은 한 다이얼이 아니다

축이 넷이고 각각 답이 다르다. **한 다이얼로 놓고 중간을 찾으면 최악이 나온다.**

| 축 | 설정 | 이유 |
|---|---|---|
| **동사** (뭘 하는 게임인가) | **보편 극단** | 0.5초 안에 이해돼야 클릭하고, 60초 안에 이해돼야 안 나간다 |
| **소재** (무엇으로) | **차별 극단** | 썸네일에서 "본 적 없는 그림"이 되는 자리 |
| **시스템** (날씨·이벤트·시즌) | **보편** | 유저가 이미 문법을 안다 = 설명 비용 0. **단 판매 포인트는 못 된다** |
| **구조** (조리·세트·배수) | **차별** | 발견 화면에 안 보인다 = **유입이 아니라 체류 장치** |

### 5-1. 브레인롯 아류가 묻히는 이유

**두 축(동사·소재)이 동시에 겹쳐서**다. 보편해서 묻히는 게 아니다.
⚠️ **중간이 가장 나쁘다** — 동사가 반쯤 낯설면 이해에 3초가 걸려 클릭이 안 되고,
소재가 반쯤 낯설면 썸네일이 기억에 안 남는다. 익숙함의 이득도 신선함의 이득도 못 받는다.
✅ Gakuran 이 증거: **동사는 100% 복제, 미학은 100% 교체.** 중간이 아니다.

### 5-2. 우리 채점

```
동사   "음식을 모아 요리한다"    ✅ 보편 극단. 좋다
소재   나라별 음식             ⚠️ 차별이 아니라 "중간"일 위험
```
⚠️ 레스토랑·음식 게임은 이미 흔하고(컨베이어 스시·병철이네·타이쿤류),
**"나라별 컬렉션"은 썸네일 한 장에 안 보인다.** 여기가 진짜 리스크다.

### 5-3. ✅ 그래서 썸네일 퍼스트 — 게임보다 먼저 만든다

소재의 차별은 **썸네일 한 장으로 증명돼야 한다.** 발견 화면에서 주변 20개와 나란히 놓았을 때
눈에 띄는가가 유일한 질문이고, **게임을 다 만든 뒤에 물으면 늦다.**

✅ **KvR 에서 이미 실측으로 안다** — 1차 광고의 유일한 통과 지표가 아이콘 CTR 1.59%(벤치 1.2%)였고,
크리에이티브별로 1.63% / 1.09% / 1.22% 로 갈렸다. **썸네일이 퍼널 앞단을 혼자 결정한다.**
→ 회색박스가 돌아가는 상태에서 소액($10) 광고로 **CTR 만 사서** 소재 후보를 가른다.
⚠️ 빈 게임에 광고를 태우면 평점이 깎인다 → **연출 계단 회색박스와 묶어서 같이 돌린다.**

### 5-4. 🔴 구조 차별은 유입에 기여하지 않는다

조리 층 · 나라별 세트 · 조합형 배수는 전부 **소진 지연 장치**지 유입 장치가 아니다.
⚠️ 이전에 *"Unbox ASMR 과 차별점이 둘뿐"* 이라며 유입을 걱정한 건 **축을 섞은 것**이다.
유입 차별점은 소재(썸네일)이고, 저 셋은 체류 장치다.

✅ **예외 하나: 구조가 만드는 "순간"이 15초 클립이면 유입에 기여한다.** 우리는 Mythic 개봉이 그 자리.
✅ **그리고 진입장벽 걱정은 유입 축이 아니라 체류 축에서 생긴다** — 답은 3-8 의 점진적 해금이다.
처음부터 다 보여주면 장벽이고, 순서대로 열면 장벽이 아니다.

### 5-5. ⚠️ 진짜 위협은 차별성이 아니라 입장료 인플레

날씨·이벤트·시즌·거래·펫이 보편화됐다는 건 **유저 기대치가 올라갔다**는 뜻이다.
이제 없으면 "덜 만든 게임"으로 읽힌다. → **차별화 문제가 아니라 최소 사양 문제**이고,
1인 개발자에게는 이쪽이 훨씬 무겁다. *"입장료를 1인이 낼 수 있나"* 가 더 정확한 질문.

✅ **해법: 입장료를 따로 다 내지 말고, 하나가 두세 개 값을 하게 번역한다.**
```
날씨  →  "오늘의 제철 재료"
         입장료 충족 + 나라별 로테이션의 이유 + 재방문 트리거를 하나로 산다
이벤트 →  미식평가단 방문 (이미 설계에 있다)
```
🔴 **이게 5절 딜레마의 최종 해답이기도 하다 — 번역은 중간이 아니다.**
시스템의 **기능**은 100% 보편(유저가 문법을 안다), **표현**은 100% 차별(제철 재료는 날씨가 아니라
음식의 언어다). 두 축을 각각 극단에 놓는 것이지 절충이 아니다.

## 7. 살아남은 설계 원칙

- 획득 동작은 **최소 2층 입력** / **핵심 루프 5분 내 완결**
- **"비어 있다"를 기회로 읽지 말 것** + **"쉬워 보인다"를 기회로 읽지 말 것**
- 3D 모델링 / 캐릭터 애니메이션이 **콘텐츠 단위마다** 필요한 구조는 피할 것

- 위생점검은 **벌점이 아니라 보너스 미획득**으로
- 아트: 리얼리즘보다 **과장·초현실·화려한 색**
- **포화 장르의 빈칸은 "장르"가 아니라 "미학 × 장르의 교차점"이다**(Gakuran) → 단 미학은 **이미 큰 팬덤**이어야
- **진입 하한 0 이 재미 상한보다 크다**(GaG) → 첫 10분의 마찰을 최우선으로 깎는다
- **보편/차별은 한 다이얼이 아니다**(5절) → 축마다 극단으로 설정. 중간이 최악

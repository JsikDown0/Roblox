## 2. 🔴 수명 곡선이 두 종류다

```
콘텐츠가 유한 (수집형)   Unbox ASMR   6주 만에 97% 증발
콘텐츠가 사람 (RP·PvP)   Da Hood      피크가 6년 전인데 아직 2,800 + 매일 업데이트
```

**RP 류가 안 죽는 이유 = 콘텐츠가 다른 플레이어라서.** ⚠️ **그런데 그게 정확히 콜드 스타트다.**
Da Hood 45인 · Baddies 22인 · Gakuran 50인 — 서버가 차야 게임이 존재한다.

✅ **가져올 것: 바닥을 높이는 방법 = 사람을 얇게 얹기.**
→ 가장 싼 형태: **남의 식당에 손님으로 방문.** 평소엔 NPC, 진짜 유저가 오면 보너스.
   = **"경합은 상한, 하한은 솔로" 규칙 그대로.** 상세는 설계 문서 8절.

## 3. 후드/갱스터류 — 기각

**09-06 기준 5개 중 5개 위반:** 콜드 스타트가 장르의 본질 / 총·스킨 = 관객 필수 코스메틱 /
전투 메타 + 그리핑 / 확장이 맵·모델(3D 약점 정면) / 업데이트가 Da Hood 13시간 전 · Baddies 3시간 전.

**+ 6번째 (09-06 에 없던 것): 모더레이션 유지비.**
설명문에 증거가 남아 있다 — Da Hood *"계정 10일 이상만 입장"*(알트 어뷰징),
South Bronx *"RK 금지 · RP 룰 위반 시 밴"*. **코드 유지비가 아니라 사람 관리 유지비다.**
⚠️ 밸런스는 자는 동안 안 돌지만 모더레이션은 24시간 돈다. 1인에게 가장 무거운 항목.

**"맵만 있으면 된다"는 착각:** 코드는 단순한 게 맞다. 하지만 **복제 가능한 게 가장 싼 부분**이다.
Da Hood 의 실체는 7년간 쌓인 유저 문화·크루·거래 시세·틱톡 생태계고, 맵을 100% 베껴도 그건 0 이다.
⚠️ 쉬우니까 이미 수백 개다 — South Bronx 파생만 COMP/Elite/FFA/Remade 네 개, RoStreets 는 추적조차 안 됨.
→ 원칙: *"비어 있다를 기회로 읽지 말 것"* + **"쉬워 보인다를 기회로 읽지 말 것."**

## 4. Gakuran — 포화 장르에서 신규가 뜬 방법

```
2025-11-19  출시
2026-07 중순 누적 8,700만
2026-08-02  New Town 업데이트 — 초희귀 Ali 스타일 · 듀얼 스타일 슬롯 · 신규 마을 · 헤어 ID 196개
2026-08-07  CCU 25.6K · 누적 1.62억   ← 3주 만에 방문 2배
2026-08-09  Wing Chun · 농구 개편 · 스케이트보드    2026-08-15  노래방 · 야키니쿠 · Striker
2026-08 중순 피크 142,296  →  2026-09-14 현재 10,952
```

**방아쇠는 틱톡이 아니라 업데이트 연쇄다.** 패치가 7/8 · 7/11 · 7/20 · 8/1 · 8/9 · 8/15 · 8/22.
9개월 축적 뒤 4~6주 폭발이었고, 단발 바이럴 형태가 아니다.

**틱톡은 증폭기다. 증폭된 이유는 설계에 있다** — 검색어가 전부 *fighting style* 계열이다.
**클립의 재료가 게임 안에 설계돼 있었다**: 초희귀 뽑기 = 극단적 결과 / 전투 = 남의 손해가 내 이득 /
둘 다 15초 완결 → 09-06 의 클립 3조건과 일치.

### ⭐ 구조가 아니라 미학을 바꿨다

뼈대는 Da Hood 와 같다(50인 · RP · 전투 · 리롤). 바뀐 건 **2007년 일본 학원 불량학생 미학 +
애니메 전투**뿐이다. 기존 셋이 전부 미국 후드 미학이었고, 애니메 층에는 배달된 적이 없었다.

→ **포화 장르의 빈칸은 "장르"가 아니라 "미학 × 장르의 교차점"이었다.**
✅ 구조 차별화는 성공의 필요조건이 아니다. ⚠️ 단 미학은 **이미 큰 검증된 팬덤**이어야 한다.

⚠️ **그 콘텐츠 펌프를 1인은 못 돌린다** — 한 패치에 헤어 ID 196개.
그리고 **주 1회를 돌리는 팀조차 피크에서 4주 만에 92% 가 빠졌다.**

## 5. 🔴 Grow a Garden — 가장 큰 요소는 "마찰 0" 이다 `[추측]`

**359억 방문 · 피크 22,375,597 · 4인 서버 · 현재 35,466.** 출시 2025-03-25, 11시간 전에도 업데이트 중.

### 5-1. 22M 은 "좋은 게임" 숫자가 아니라 "아무도 튕겨나가지 않는" 숫자다

로블록스 최상위 히트작들이 피크 10~20만이다. 22M 은 자릿수가 두 개 다르다.
그 숫자는 재미의 상한이 아니라 **전달 효율**에서 나온다.

```
바이럴 계수 ≈ (전달받은 사람) × (들어와서 이해하는 비율) × (남에게 말하는 비율)
```

대부분의 히트작은 **가운데 항에서 샌다** — 친구 추천으로 들어왔는데 60초 안에 뭘 할지 모르면 나간다.
GaG 는 가운데 항이 1 에 가깝다. *"씨앗 심고 기다렸다 수확한다"* 는 여섯 살도 즉시 이해한다.

**마찰이 모든 축에서 0:**
```
스킬 0     못할 게 없다
시간 0     하루 5분이 완전한 경험
기기 0     4인 서버 + 정원 하나 = 저사양 폰에서 돈다
손실 0     죽지도 뺏기지도 않는다
사회 0     친구 없어도 성립
학습 0     설명이 필요 없는 동사
```

→ **GaG 는 재미의 상한을 높인 게 아니라 진입의 하한을 없앴다.** 로블록스 규모에서는 후자가 압도적이다.
⚠️ 사용자 지적(*"농사는 굉장히 베이직한 장르"*)이 정확한데, **베이직한 게 약점이 아니라 그게 메커니즘이었다.**

✅ **구조적 증거: 서버 4인.** 사용자가 *"채팅 문화가 우세하지 않다"* 고 본 게 맞고, 우연이 아니다 —
4명이면 사회가 성립할 수 없다. **GaG 는 사회층을 포기하고 마찰 0 을 샀다.**
= 2절의 "저점은 사람이 만든다"와 **정반대 전략이고, 둘 다 성립한다.** 저점을 사회로 살 수도 있고,
유입 폭으로 살 수도 있다.

### 5-2. 2순위 — 배수 구조(뮤테이션)가 "다 모으면 끝"을 깬다

마찰 0 은 유입만 설명하고 체류를 설명 못 한다. 그 자리에 뮤테이션이 있다.
같은 당근이 Gold · Rainbow · 날씨(Wet/Chilled/Shocked…)가 **곱해져** 1배에서 수천 배가 된다.

```
Unbox ASMR   희귀도 = 새 물건        → 다 모으면 끝난다 (6주)
GaG          희귀도 = 기존 것에 곱하는 배수 → 같은 씨앗을 계속 심을 이유가 남는다
```

🔴 **컬렉션은 유한하지만 배수는 무한하다.** 이게 설계 문서 7절 최대 빈칸("같은 패턴 반복을 무엇이 막나")의
가장 강한 답 후보다.

✅ 우리 "종류는 확정 · 품질은 확률"이 이미 이 형태다.
⚠️ **다만 GaG 는 배수가 곱해진다**(Gold × Wet × Shocked). 우리 품질은 단일 등급이라 조합 폭발이 없다.
→ **품질을 단일 등급이 아니라 조합형 배수로 바꾸면** "같은 요리를 또 만들 이유"가 자릿수로 늘어난다.

### 5-3. 3순위 — 날씨 = 손실 없는 서버 이벤트

4인 서버에 사회가 없는데도 "혼자가 아니다"를 만든 장치. 비가 오면 내 밭 전체에 Wet 이 붙는다.
지금 접속해 있을 이유 + **경합이 아니라 공유 상승**(남이 이득 봐도 내 손해가 아님) + "뭔가 일어났다".

⚠️ **그리고 비예고다.** 설계 문서에 *"방문 이벤트는 예고제로"* 라고 적혀 있는데, GaG 는 반대를 택했고
그게 통했다. 저연령층은 접속 시간 통제권이 없으니 **비예고 + 잦음**이 오히려 맞을 수 있다 `[추측]`.
→ 설계 문서 5절의 예고제 원칙은 **재검토 대상**이다.

### 5-4. ⚠️ 이레귤러라는 지적이 맞다 — 그리고 붕괴는 더 심하다

현재 35,466 = **피크의 0.16%.** 붕괴율로는 Unbox ASMR(2.6%)보다 심하다.
다만 절대 바닥이 35K 라 여전히 로블록스 최상위권이고 359억 방문을 뽑았다.
→ 배울 것은 *"22M 가는 법"* 이 아니라 **"마찰을 어디서 없앨 수 있나"** 하나다.

### 5-5. 🔴 우리 설계 마찰 점검 — 자기 교정

| 축 | 우리 | 판정 |
|---|---|---|
| 학습 | "음식 모아서 요리한다" | ⚠️ **재료→레시피→조리→품질**은 "심고 기다린다"보다 층이 많다 |
| 스킬 | E키 + 접시 선택 | ✅ |
| 시간 | 접속 5분 | ✅ |
| 기기 | 벨트 + 뷔페 홀 + 식당 + NPC 손님 | ⚠️ **GaG 의 4인 정원보다 무겁다** |
| 손실 | 없음 | ✅ |
| 사회 | 없어도 성립 | ✅ |

⚠️ **걸리는 두 개가 전부 2026-09-14 세션에 내가 추가한 것이다** — 조리 층과 사회층.
재미를 위해 층을 더하는 동안 마찰이 늘었다.

✅ **해법: 층을 빼지 말고 동시에 보여주지 않는다. 첫 10분은 GaG 만큼 단순해야 한다.**
```
1분차   벨트에서 음식 집는다 → 집에 놓는다 → 돈 번다. 끝.
그 뒤    N개 모으면 조리가 열린다
그 뒤    식당·손님이 열린다
그 뒤    품질·세트·환생
```
⚠️ **이건 튜토리얼이 아니라 점진적 해금이다.** 09-06 의 *"Gamefam 은 튜토리얼 제거로 D1 이 올랐다"* 와
충돌하지 않는다 — 튜토리얼은 **설명**이고 해금은 **아직 존재하지 않는 것**이다. 설명할 게 없으면 마찰도 없다.

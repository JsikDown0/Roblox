## 0. 컨셉

**먹을 수 없는 것을 요리해서, 찾아온 요괴에게 먹인다. 만족한 요괴는 내 가게에 눌러앉는다.**

```
재료      쇠 · 벽돌 · 돌 · 나무 · 볼트 · 전구 · 자석 …   ⚠️ 좀비 제외 (3-4)

소비처    찾아오는 요괴 손님 / 가끔 나타나는 레이드 보스
컬렉션    눌러앉은 요괴들 (3-3 · 3-6)
톤        캐주얼 호러 · 이상현상 (변칙성 병원류)
```
착안: 기네스북의 "쇠를 씹어먹는 남자" `[경험]`

### 0-1. 🔴 동사는 하나 — "먹인다"

원안은 동사가 셋이었다(파밍 + 요리 + 손님 킬/보스에 던지기). 4축 원칙 *"동사는 보편 극단"* 위반.
✅ **보스에게 "던진다"가 아니라 "먹인다"로 통일.** 손님도 보스도 먹는 대상.
```
캔다 → 요리한다 → 먹인다 → 반응 → 눌러앉는다
```

## 2. 음식 버전 대비 무엇이 나아졌나

| | 음식 수집 | 요괴 손님 |
|---|---|---|
| **썸네일** | ❌ 나라별 컬렉션이 한 장에 안 담긴다 | ✅ **괴물이 못을 씹는 그림** — 부조화 + 캐릭터 + 반응이 한 장에 |
| **컬렉션 축** | 나라별 세트 | ✅ **요괴 도감 + 눌러앉은 요괴** |
| **컬렉션 가시성** | ❌ 집에 있어 광장에서 안 보인다 (최대 구멍) | ✅ **가게에 떠 있다 — 방문자가 한눈에 읽는다** (3-6) |
| **반응체** | NPC 손님을 따로 붙여야 했다 | ✅ 먹이는 게 코어 |
| **연령 리스크** | 없음 | ✅ "킬"이 "접대"가 되어 해소 |
| **모델 비용** | 음식 모델 필요 | ⚠️ 요괴 = 콘텐츠 단위 (2-1, 3-6) |

**썸네일이 경쟁하는 축이 다른 게 핵심이다.** 발견 화면이 "빛나는 거대한 아이템 + 형광 그라데이션"으로
수렴해 있는데, 엽기는 **빛이 아니라 의미의 부조화로 경쟁한다.**

### 2-1. ⚠️ 모델 비용 — 미학이 그 비용을 낮춘다

요괴 확장 = 모델 + 애니메이션 → 09-06 원칙 *"콘텐츠 단위마다 모델·애니가 필요한 구조는 피할 것"* 위반.
✅ **캐주얼 호러는 추상 형태가 허용되는 미학이다.** 사람 손님은 리깅 + 워크 애니가 필요하지만
**떠다니는 눈알 덩어리 · 그림자 · 입만 있는 것**은 Part 몇 개 + 회전이면 된다.
+ 재료는 기본 Part 에 Material 만. Blender 텍스처 파이프라인은 이미 있다.

## 3. 🔴 요괴의 규칙 · 수집 대상 · 재료 선

### 3-1. "규칙이 외형에 적혀 있다" — 퍼즐 vs 뽑기 이분법을 깬다

사용자 안: 이상현상 시리즈 / Good Pizza, Great Pizza 처럼 **손님마다 간단한 규칙**.
예 — **못 박힌 괴물은 못이 들어간 걸 좋아한다.** `[경험 기반 착안]`

**규칙이 외형에 적혀 있으면 퍼즐인데 학습 마찰이 0이다.** 튜토리얼도 도감도 필요 없다.
✅ 맞물리는 원칙: **마찰 0** / **"서로를 읽을 수단"** / **점진적 해금**(난이도 = 규칙이 몸에 적힌 정도)

```
1단계  못 박힌 괴물  → 못을 넣는다          외형 = 답 (마찰 0)
2단계  녹슨 괴물     → 쇠? 물? 둘 다?       외형이 힌트지만 애매
3단계  거울 괴물     → 자기가 먹은 걸 원한다  규칙이 조건부
```

### 3-2. ⚠️ 한 번 풀면 끝난다 — 품질이 그 자리를 메운다

못 괴물은 영원히 못이다. 답이 고정이면 반복 동기가 없다.
✅ **종류(답)는 확정, 품질은 조합형 배수.** 확장 후보: **두 요괴가 같이 올 때**.

### 3-3. 🔴 수집 대상은 요리가 아니라 요괴다 `[결정 방향]`

**질문: 무지개 당근은 갖고 싶은데, 눈알 사탕이나 강철 버거도 갖고 싶을까?**
→ **웃김과 소유욕은 다른 감정이고, 수집 게임의 엔진은 소유욕이다.**

반례는 크다 — Steal a Brainrot 은 통째로 못생겼는데 수백만이 수집하고, Doors 엔티티는 굿즈가 나온다.
갈림길은 **캐릭터성**이다:
```
요괴 (생물)       기괴해도 귀여워질 수 있다  → 수집 대상으로 성립
눈알 버거 (무기물)  캐릭터성이 없다          → 그냥 징그럽다
```
✅ **요리는 열쇠, 요괴가 트로피다. 요리는 도감에 안 들어간다.**

⚠️ **GaG 당근도 당근이 예뻐서 갖고 싶은 게 아니다** — 무지개로 빛나고 집채만 해서다.
소유욕을 만드는 건 소재의 미적 매력이 아니라 **희소성 표식이 읽히는 것.**
**단 베이스가 혐오스러우면 표식을 얹어도 혐오가 남는다** → 3-4 가 선행 조건.

### 3-4. 🔴 재료 선 — "먹을 수 없는 것"이지 "역겨운 것"이 아니다 `[결정 방향]`

```
✅ 쇠 · 벽돌 · 돌 · 나무 · 볼트 · 전구 · 자석      부조화만 남는다
❌ 좀비 · 벌레 · 내장 · 상한 것                    혐오가 남는다
```
⚠️ **원안의 "좀비"가 선을 넘는다.** 좀비 = 부패 = 혐오이고,
**사람은 먹는 것에 대한 혐오가 유독 강하다** — 다른 건 웃고 넘어가도 음식은 안 넘어간다.
✅ 부수 효과: **썸네일 색이 산다.** 못 박힌 케이크는 밝고 선명하지만 좀비 버거는 탁해진다.

**아트 규칙**
```
❌ 사실적인 눈알 · 피 · 부패 · 벌레 질감
✅ 둥글고 큰 눈 · 만화적 하이라이트 · 높은 채도
```
**"징그러운 것"이 아니라 "말이 안 되는 것"이 웃김의 원천이어야 한다.**
예시 판정 — *"번개 맞아 지직거리는 강철 버거"* ✅ / *"무지개 눈알 사탕"* 은 눈알이 사실적이면 ❌,
만화적이면 ✅(사탕 베이스라 형태는 이미 귀엽다).

### 3-5. 🔴 경계 — 주문 처리로 가면 장르가 바뀐다

**"손님 주문을 시간 안에 처리한다"는 순간 수집 시뮬이 아니라 서빙·타임매니지먼트 게임이다.**
✅ 선: **요괴는 "처리할 주문"이 아니라 "수집할 대상"이다.**
❌ 시간 압박 없음. 대기열 없음. 실패 페널티 없음(손실 없음 원칙).

### 3-6. 🔴 표식은 요괴에게 붙는다 — 그래서 요괴는 떠나지 않는다 `[결정 방향]`

**질문: GaG 는 거대 작물이 자연스러운데, 거대한 요리는 억지 아닌가.** → 맞다. 그래서 **요리에 안 붙인다.**

✅ **만족한 요괴는 내 가게에 눌러앉는다.**
- **컬렉션이 UI 목록이 아니라 세계에 있다.** 도감은 진행 표시, 실물은 가게에 떠 있다
- **품질이 요괴에 붙는다** — 크기 · 광택 · 오라 · 색.
  **거대하고 무지개로 빛나는 괴물은 완전히 자연스럽다** (거대한 버거와 달리 억지가 없다)
- = **GaG 의 뮤테이션을 작물이 아니라 생물에 옮긴 것.** 생물은 그 표식을 원래 잘 받는다

✅ **음식 버전의 최대 구멍이 자동으로 풀린다** — 컬렉션이 집에 있어 남이 못 읽는 문제.
누가 내 가게에 오면 내가 뭘 모았는지 **한눈에 보인다.** "접시 위 요리를 들고 다니자"가 필요 없어진다.

⚠️ **정직한 비용: 5-1 의 이점이 일부 되돌아온다.** "손님은 순차로 와서 화면에 1~2마리면 된다"가
눌러앉으면 약해진다.
→ 완화: **눌러앉은 요괴는 정적 장식이다.** AI 없음, 둥둥 뜨는 idle 하나.
  저택은 방마다 **게임플레이**가 필요했고 여기는 **장식**이다. 그래도 **전시 슬롯 상한을 둔다.**

**요리 쪽의 축 (얕게만)**
**"거대"가 아니라 "높이 쌓기"** 가 음식의 자연스러운 축이다(버거 스택은 이미 밈 문법).
+ 삐져나온 못 · 튀는 스파크 · 은쟁반. 서빙 순간만 읽히면 되므로 깊게 가지 않는다.
✅ **최고 품질 요리 하나만 유리 돔에 박제** — 명예의 전당 한 칸. 개수가 적어 비용이 없고
"만들었는데 바로 사라진다"는 허무함을 덜어준다.

## 4. 🔴 획득 경로 — 셋을 하나로 줄인다

사용자 안: ①요괴 시장 ②폐병원 등 장소 파밍 ③희귀는 선착순.
**사용자 본인이 "짬뽕 같다"고 느낀 게 정확하다** — 경로가 셋이고 각각 다른 장르의 문법이다.
GaG 도 Unbox ASMR 도 획득 경로가 **하나**다.

```
코어 (1분차)   요괴 시장          로테이션 = 리듬 = 세션 엔진. 익숙한 문법이라 마찰 낮음
해금 (2단계)   폐병원 등 장소 파밍  시장에 없는 재료. 썸네일·미학의 실체가 여기 있다
상한           희귀 선착순         시장의 희귀 재고에 붙인다 — 경합이므로 하한이 될 수 없다
```

**왜 시장이 코어인가** — 로테이션이 리듬을 만든다 = 세션 엔진 조건 충족. 탐험은 한 번 다 보면 끝이라
코어면 소진이 빠르다. 맵 비용도 던전보다 압도적으로 싸다. "요괴 시장"은 그 자체로 호러 이미지다.

**왜 폐병원이 해금인가** — ⚠️ 시장에서 사기만 하면 **못이 그냥 아이템이 된다.** 직접 뽑아와야
*"이걸 먹인다고?"* 가 산다. 썸네일 소재도 여기서 나온다. 반복성 완화는
**갈 때마다 배치·이상현상이 바뀌게** — 이상현상 미학과 정합.

⚠️ **선착순은 반드시 상한으로.** 동접 0 이면 그냥 내가 다 가져가면 된다.

## 5. 🔴 옛 "유령저택" 컨셉과의 관계 — 기록이 없다

**프로젝트 문서와 메모리를 전수 검색했으나 유령저택은 어디에도 없다** `[실측 2026-09-14]`.
🔴 **부재 자체가 교훈이다 — 대화로 죽은 컨셉은 이유가 안 남고, 나중에 같은 아이디어가 다시**
**매력적으로 보인다.** 음식 버전을 문서로 남긴 이유가 이것이다.

**사용자 기억상의 기각 사유** `[기억]`: ①유령 모델링 ②구현 복잡도.

**① 모델링 — 난이도가 아니라 필요 개수였을 가능성**
```
저택    공간이 콘텐츠 → 방마다 유령 → 방을 늘리면 유령이 선형으로 는다
손님    순차로 온다   → 화면에 1~2마리면 된다
```
⚠️ 단 **3-6(눌러앉기)이 이 이점을 일부 되돌린다.** 정적 장식이고 슬롯 상한이 있다는 점이 다르다.
✅ 도감이 늘어나는 건 **콘텐츠 확장이지 출시 요건이 아니다.** 8종으로 내고 천천히 늘린다.

**② 구현 복잡도 — 이미 미뤄놓은 배치다**
```
저택    방 전환 · 문 · 시야 · 추격 AI · 숨기 · 공포 연출 타이밍 = 호러 게임 시스템 전부
먹이기  손님이 와서 선다 → 준다 → 반응한다.  AI 가 거의 없다
```
✅ 4절의 "시장 코어 / 폐병원 해금" 배치가 정확히 이 복잡도를 미루는 형태다.

### 5-3. ⚠️ 가드레일 — 저택이 뒷문으로 돌아온다

**폐병원 파밍을 해금할 때 그때 접었던 복잡도가 그대로 따라온다.**
✅ **해금 콘텐츠라도 "탐험 게임"이 아니라 "재료 캐는 장소"로 범위를 못박는다.**
❌ 적 AI 없음 · 추격 없음 · 사망 없음.
⚠️ **여기서 한 발짝 더 나가면 유령저택을 다시 만드는 것이다.**

## 6. 상속하는 것 (음식 문서에서 그대로)

- **경합은 상한, 하한은 솔로** → 레이드 보스·선착순 둘 다 상한
- **세 엔진** → 조리(오프라인·D1) / 먹이기 반응(실시간·짜릿함) / **시장(세션 엔진)**
- **대기 임계** → 실시간 대기는 1분 미만. 분 단위는 이탈 장치
- **종류는 확정 · 품질은 조합형 배수** → 품질은 **눌러앉은 요괴의 외형 + 도감 최고 기록**에 붙는다
- **점진적 해금** → 첫 10분은 "산다 → 요리한다 → 먹인다" 하나만
- **손실 없음** → 손님은 반드시 NPC
- **연출 계단 5단** → 요괴의 반응이 등급의 함수
- **환생** → 리셋: 코인·설비 / **영구: 요괴 도감(종류 · 품질 최고 기록)**
- **썸네일 퍼스트** → 게임보다 먼저 세 장 만들어 발견 화면에 끼워본다
